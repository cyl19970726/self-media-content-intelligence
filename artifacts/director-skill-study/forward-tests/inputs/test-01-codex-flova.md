# Forward test 01 — 单条搜索/收藏教程

模式：single，小红书优先。

账号方向：帮助独立创作者真实使用 AI 完成视频，而不是只讲新闻。账号处于早期，尚无稳定粉丝基线。

选题：`Codex + Flova 做视频前先看`。现有评论需求来自四类问题：价格、Windows/Mac 兼容、能否剪自己的素材、封面怎么做。这里只能把这些当用户需求线索，不能声称代表所有用户。

可用素材：

- 一次从指令到 Flova 项目生成的真实屏幕录制；
- 一段最终 9:16 短片；
- 自己创建的 `.md` 工作习惯文件；
- 可以重新录制旁白和补拍桌面操作；
- 没有可公开的用户后台转化数据，也没有权限使用别人的评论头像。

约束：1 人制作，半天拍摄剪辑，60–90 秒；不得承诺免费、万能、自动完成或平台流量；价格与兼容性若没有当前官方证据必须标未知或改成核验步骤。

请使用 deep-content-director 产出完整 `directing-brief.json` 和可读 Markdown 方案，并运行 Skill 的 validator。重点检验：单条任务是否清楚、前 12 秒是否披露 Flova 依赖、证明链、镜头功能、标题/封面、唯一变量实验和复盘判断。
