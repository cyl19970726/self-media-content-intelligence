# Forward test 02 — 热点比较内容

模式：single + review，小红书优先。

账号方向：为内容创作者解释 AI 工具与工作流，强调实测、边界和决策，不追求纯新闻搬运。

选题：DeepSeek 最近讨论度高，想做“它哪些地方做得好、哪些地方不符合预期，为什么有些帖子好、有些帖子差”。当前没有提供后台数据、帖子样本或官方最新材料。

约束：不要编造“最近”、热度、平台数据、留存或帖子因果。若外部检索不可用，必须把事实研究列为发布前 Gate；仍需给出一个可以执行的选题研究方案、3 个真正不同的内容角度，并选择一个形成 75 秒以内的脚本/镜头/发布实验。一个人、一部手机、可录屏，可在一天内完成。

请使用 deep-content-director 产出完整 `directing-brief.json` 和 Markdown，并运行 validator。重点检验：面对缺证据时是否仍可推进但不造事实；是否区分热点注意、账号承诺与搜索长尾；是否把“好/差”转成可观察判断，而非主观打分。
