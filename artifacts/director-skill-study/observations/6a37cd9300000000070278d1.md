# Observation：用户—需求—场景—选题—迭代

角色：重点学习。两轮修复后由第三位独立 evaluator 通过 22/22 Gate。

## O1 内容方法

- 作者把好内容映射为三种心理结果：好奇、认同、得到；相应动作是精准兴趣、场景共情和自然满足需求。
- 创作链为用户 → 需求 → 场景 → 选题 → 迭代；发布不是终点，评论语义和数据共同进入下一轮选题。
- 搜索用户偏效率，闲逛用户需要降低内容的强目的感；同一知识要适配使用语境。
- IP 可以设计但不能造假；爆款系列比孤立单条更有账户价值。

## O2 表达方法

- 以五万粉状态和“官方创作指南”建立权威，再将书中框架、自身旧方法和作者推论交织讲解。
- 白板持续承载结构，讲义/书册成为 proof object；但“官方来源”和具体活动关系没有完全证明。
- 静安寺例子用“画面提供事实、口播增加感受”解释跨载体互补，虽未真正插入现场画面。
- 结尾回到课程系列，但不验证开场涨粉和 30 天结果承诺。

## O3 反问

1. 好奇、认同、得到可能并存，应标主心理结果而不是硬分类。
2. “平台需留住用户，所以平台与用户目标一致”忽略商业、治理、短期刺激与长期价值差异，只能保留为作者论证。
3. 搜索/闲逛意图如何识别？标题、入口和后台来源需要实测，不能仅靠创作者猜测。
4. 评论跑题可能说明内容偏差，也可能说明人物吸引力、评论样本偏差或预期外价值；应结合行为数据。
5. 画面与口播互补不等于永不重复；关键步骤和高风险信息可能需要冗余确认。

## O4 可迁移

- 用五步链做每条内容的前后闭环：需求证据进入选题，发布反馈必须能回到下一轮修订。
- 每个信息载体指定功能：画面证明/展示，口播解释/感受，字幕标记结构；只有必要信息做有意冗余。
- 开拍前写主心理结果与次心理结果，避免既要好奇、共鸣、教程又要成交。
- 把“设计 IP 不造假”落成事实检查：身份词、成绩、截图和案例分别注明来源与证明范围。

## O5 实验

- 同题做搜索效率版与闲逛叙事版；分别追踪搜索曝光/收藏和首页留存/转发，守护有效关注。
- 复盘评论时编码为目标理解、意外价值、人物讨论、疑问和反对，而不是只数正负面。
- 对事实—感受互补版与口播画面重复版做可理解性测试，记录关键步骤召回与流失。

## O6 修订

- 当前状态：`repeated_pattern`。用户优先、系列、反馈迭代和跨载体功能在多条重点样本重复；平台目标一致和固定心理分类仍为 hypothesis。
