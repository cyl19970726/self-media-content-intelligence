# Observation：一条作品不必同时负责所有结果

角色：辅助学习。重建与独立复评均已通过 22/22 Gate。

## O1 内容方法

- 先区分依靠既有身份/IP 的账号与依靠策划、选题、拍摄和后期的内容型账号，再决定内容投入方式。
- 把单条作品使命拆成数据、涨粉、商业、调性和表达；一条作品不必同时完成五种任务。
- 数据差不必然等于作品失败：若预先任务是商业承载、账号调性或表达，评价指标应随任务改变。
- 用户、市场、平台和创作者条件共同限制作品；“作品使命”是把这些约束转成决策的中间层。

## O2 表达方法

- 开头用平台数字拼贴和综艺素人案例先制造“内容弱也能涨粉”的冲突，再给出 IP 型/内容型框架。
- 中段不断使用反常识对照：手势舞数据好但内容弱，Vlog 数据差却可能承担商业任务。
- 面罩、白板、手势和强断言形成固定教师人设；视觉稳定降低解释复杂框架的认知成本。
- 例子让抽象的作品使命可见，但成绩、报价和普遍因果都没有在片内验证。

## O3 反问

1. IP 型与内容型是否是互斥类别，还是账号在不同阶段、不同栏目中的连续谱？
2. 如果一条内容只负责调性或商业，什么指标能防止团队事后为低数据找借口？
3. “普通人只能走内容型”忽略了职业身份、关系、经历和审美也可逐步成为 IP 资产。
4. 数据、涨粉、商业、调性、表达之间会相互促进或冲突，视频没有给出组合优先级。
5. “装13型视频”与 SRT 错词、干货型层级不清，说明类别名必须依赖多载体核对，不能只抄字幕。

## O4 可迁移

- 每条 brief 在写脚本前只指定一个主任务，并最多指定一个守护任务；其余结果不作为当次成功标准。
- 建立账号级内容组合：获客内容、关注承接、信任证明、商业承载、审美/价值表达各自有席位。
- 把“IP 型/内容型”改成可观察的资产盘点：既有身份信号、证明材料、表达能力、制作能力和分发渠道。
- 不迁移“普通人只能怎样”及报价、增长因果；它们保留为作者主张。

## O5 实验

- 连续 12 条内容发布前标注主任务；主指标分别使用曝光效率、有效观看后关注率、咨询/点击、主页深读或定性反馈。
- 每四条做一次组合复盘，检查是否长期只有获取内容而没有关注承接与信任证明。
- 同主题制作“身份/结果证明开场”和“用户问题开场”，比较 3 秒留存、有效观看后关注率；不得用总点赞替代。

## O6 修订

- 当前状态：`single_observation`。作品任务拆分与另一条“爆款≠涨粉”形成重复方向，但五任务分类仍需保留集与真实发布数据验证。
