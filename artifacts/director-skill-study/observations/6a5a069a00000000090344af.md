# Observation：投入强度与方向选择是两层决策

角色：辅助学习。重建与独立复评均已通过 22/22 Gate。

## O1 内容方法

- 赚钱导向内容先对齐用户需求，同时保留创作者特色和真诚；视频应像产品一样考虑用户、平台和环境。
- 投流只被定义为放大器，不能代替内容判断；养号、活跃度等说法不能成为弱作品的默认解释。
- “全力以赴”和“低数据换方向”不是矛盾：前者约束执行质量，后者约束策略假设。
- 有目的地刷内容，把 BGM、热点和剪辑手法积累成素材；普通人避免用裸辞放大未经验证的内容风险。

## O2 表达方法

- 用“十条建议”形成强清单承诺，覆盖创作者、老板、普通人和雇主等多个决策角色。
- 反讽制造认知转折：“轻松高薪”必须连同随后责任要求阅读，单摘前句会完全反向。
- 强比喻和冒犯性表达提高记忆度，也承担人设塑造；其传播价值与事实可靠性必须分开。
- 烧录字幕补回 SRT 漏失的第八条“一夜起号”，证明意义重建不能只依赖语音稿。

## O3 反问

1. “一条数据不好就换方向”缺少样本量、发布时间、分发波动和观察窗口，机械执行会过早杀死好方向。
2. “投流只锦上添花”“养号无效”都缺少后台对照，适合作为实验假设而非平台事实。
3. 用户优先怎样避免同质化？创作者特色必须落实为可识别的视角、证明或表达形式。
4. 全力投入应作用在一次可测试的版本上，而不是无限提高制作成本。
5. 十条建议跨度很大，记忆与行动优先级不清；清单完整不等于决策闭环完整。

## O4 可迁移

- 把执行复盘分成两栏：`这版有没有执行到位` 与 `这个方向是否值得继续`，不得互相替罪。
- 方向变更需预先写样本数、主指标、守护指标、观察窗口和停止线，不能凭单条情绪决定。
- 素材学习必须记录“可复用机制 + 适用条件”，而非只收藏成片。
- 保留职业风险管理和雇主预期校准；不迁移“一夜起号”、千万元门槛或唯一平台因果。

## O5 实验

- 同一方向至少发布 3 个执行合格的变体，再按预设主指标判断继续、调整或停止；同时记录自然曝光作为分发混杂项。
- 为每次付费放大设置自然版本基线，主指标看目标动作成本，守护指标看留存与负反馈。
- 每周从收藏素材中选 3 个机制做小样，不复制措辞和人设；记录采用、否定及原因。

## O6 修订

- 当前状态：`single_observation`。执行质量/方向选择分层可进入 V0 候选规则，但具体样本数和停止线必须由我们的发布实验校准。
