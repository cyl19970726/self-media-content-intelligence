# Observation：一条视频起号 1.4w

角色：重点学习。修复后重建与新 evaluator 通过 22/22 Gate。

## O1 内容方法

- 起号顺序是先定义“我是谁”和赛道，再推导目标用户、用户需求、内容、更新与变现，而不是直接拍。
- 自媒体被定义为“他媒体”：资源、用户需求与平台环境共同约束内容。
- 用户需求候选包括审美、共鸣、成长/价值、猎奇、情绪和解决问题；这是作者分类，不是穷尽事实。
- 规律更新、内容质量、投流和广告位分别服务生产稳定、放大和商业承接。

## O2 表达方法

- “一条视频起号 + 收入前三”作为高位开场，随后用白板将复杂起号压成连续步骤。
- 先用 IP 十问做自我挖掘，再由赛道进入用户；它让抽象定位变成可回答的问题。
- 以“养号不存在”“投流救不了烂内容”“没有广告位不赚钱”等强句制造记忆点，但证据主要是作者权威。
- 结尾把 Vlog 细节留到下一期，形成系列延续。

## O3 反问

1. IP 十问能生成素材，不自动生成有效定位；还需竞争、用户价值和可持续供给校验。
2. 六类需求可能重叠，也缺真实用户验证；应当允许一条内容有主需求与副需求。
3. “平台给新人 80% 流量”“养号不存在”“广告位决定赚钱”均缺平台/收益数据，不能进入硬规则。
4. 强人设是否真的带来传播，还是仅增加点开？需要看信任、关注、转化和负反馈，而非点赞关联。

## O4 可迁移

- 把账号定位写成可检验的身份承诺：服务谁、解决什么、凭什么、持续提供什么。
- 自我盘点之后必须经过用户访谈/评论/搜索和可持续生产审查。
- 付费放大只能放大已验证内容假设；在没有自然样本前不把投流当修复工具。
- 商业化在选题期考虑“自然使用场景”，但不能牺牲用户承诺或伪造植入。

## O5 实验

- 为三个候选定位各写 5 条题目，比较用户清晰度、供给难度和自然反馈，再选主线。
- 每条只设一个主要需求，同时记录次要需求；用评论语义和收藏/转发判断是否命中。
- 投流前设自然数据最低线和单一目标；投后分开记录自然/付费，不将总播放当因果证明。
