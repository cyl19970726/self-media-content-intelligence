# Observation：从用户到发布的起号 SOP

角色：重点学习。重建与独立复评均已通过 22/22 Gate。

## O1 内容方法

- 决策链为：用户与需求 → 平台风向 → 内容取舍 → IP 设计 → 选题库 → 表达准备 → 拍摄剪辑 → 发布时间。
- 自媒体被定义成“他媒体”，先选目标用户的共情、猎奇或得到需求；作者选择解决问题的“得到”。
- 起号阶段用免费深度内容换取注意，明确短期流量与即时赚钱不能同时最大化。
- IP 同时由 ID、气质判断和稳定视觉符号构成；制作 SOP 则追求手机、麦克风、简单字幕和快速剪辑的可持续性。

## O2 表达方法

- 开场以五天、五条、五万粉和百万播放建立极强结果承诺，但视觉数字与归属并不完整可证。
- “人类最强编导”先给职业类别，再用“最强”制造狂/权威；红面罩与白板形成低成本、稳定识别系统。
- 白板大纲既是讲述结构，也是画面中的方法证明；它让“不写逐字稿”仍可看见准备痕迹。
- 整条视频自身采用单场景口播，却讲完整生产链，依赖决策密度而非镜头丰富维持推进。

## O3 反问

1. 用户需求三分法是否覆盖目标人群，如何用评论、搜索和访谈验证而非凭经验选择？
2. 免费深度内容的边界和商业承接在哪里，避免吸引只要免费资料而不匹配的受众？
3. 视觉符号能建立识别，但“最强”需要什么持续 proof 才不变成空称号？
4. 晚七点发布与“饥饿耐心”没有证据；应以账号后台和分时实验替代心理故事。
5. 口述剪辑步骤不等于操作 SOP；缺少参数、完成定义、失败处理和成片验收。

## O4 可迁移

- 用这条依赖链作为 brief 前置流程，但每一步必须记录输入、决策和未验证假设。
- IP 设计拆成：可理解的身份词、可感知的态度、可重复视觉符号、可验证 proof；不复制面罩或“最强”。
- 选择可持续的最小制作系统，先稳定交付，再对复杂画面做有目的升级。
- 发布时间只做可测变量，默认使用自身后台高活跃窗口，不迁移固定晚七点。

## O5 实验

- 为一个目标用户准备“解决问题”和“情绪共鸣”两种版本；主指标分别看收藏/目标动作和有效评论/转发，守护关注率。
- 用同一内容在两个高活跃时窗轮换测试至少三次，记录自然曝光和留存，避免单次分发误判。
- 连续 6 条保持身份词与视觉系统，只改变 proof 的类型，观察主页访问后关注率和评论中的身份复述。

## O6 修订

- 当前状态：`repeated_pattern`。用户优先、稳定视觉人设、选题积累和简化生产在多条样本重复；固定发布时间与平台深度趋势仍为 hypothesis。
