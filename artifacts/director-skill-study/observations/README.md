# Observation corpus contract

本目录不是“金句摘抄”，而是从通过重建 Gate 的视频中学习可迁移编导方法。

每条 observation 必须分开记录：

1. `O1 内容方法`：视频明确教了什么；
2. `O2 表达方法`：这条视频自己怎样获取注意、推进认知和完成交付；
3. `O3 反问`：证据、适用条件、反例、冲突和未覆盖阶段；
4. `O4 迁移`：什么能进入候选规则，什么只能保留为作者主张或人设表达；
5. `O5 实验`：怎样落成我们自己的动作、主指标、守护指标和失败线；
6. `O6 修订`：发布数据或保留集是否确认、限制或否定该规则。

## 证据纪律

- 只能从已通过视频重建硬闸的 `reconstruction.json` 和 article 归纳。
- 点赞、收藏、评论和粉丝量只描述公开表现，不证明单个脚本机制导致结果。
- 同一原则至少要区分 `single_observation`、`repeated_pattern`、`contradicted`、`experiment_supported` 四种状态。
- 强人设、面具、收入声明、爆款数据拼贴分别建模；不得合并成“牛逼人设容易火”的单因果结论。
- 保留集在 V0 冻结前不可进入本目录的归纳上下文。

## 进入最终 Skill 的门槛

- 能明确对应创作闭包中的一个动作；
- 有适用条件和反例；
- 不依赖复制原博主身份、措辞或未经验证的成绩；
- 能在发布后被观察或反驳；
- 不把平台算法传闻写成事实。
