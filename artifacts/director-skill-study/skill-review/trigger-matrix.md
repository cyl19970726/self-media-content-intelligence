# Trigger matrix

用于 fresh reviewer 检查 `deep-content-director` metadata，而不是让作者自判。

## Should trigger (20)

1. 帮我做这个小红书 AI 账号的起号定位和内容矩阵。
2. 把这个选题写成 60 秒口播脚本和镜头表。
3. 这篇图文笔记的首图、标题和轮播顺序怎么改？
4. 给这个种草笔记设计证据链和商业披露。
5. 我有 10 个选题，帮我选 3 个做系列。
6. 把一次工具实测做成小红书搜索收藏型内容。
7. 这条视频前 12 秒留存差，编导上怎么改？
8. 拉片完成了，把学到的机制重构成我们自己的 brief。
9. 分析这个博主后，给我一套不复制人设的内容策略。
10. 给 7 天起号系列设计每集任务和追更理由。
11. 改造这份口播稿，让画面、字幕和口播不重复。
12. 帮我列拍摄提纲、proof shots 和剪辑取舍。
13. 这条小红书笔记收藏高但不涨粉，怎么复盘？
14. 设计一个只改变封面承诺的发布实验。
15. 做一个 DeepSeek 热点对比内容，但不要编造事实。
16. 给创始人故事做开场、转折、证明和行动闭环。
17. 企业 IP 内容如何既有用户价值又能自然商业承接？
18. 把这条长视频拆成 5 个互补短内容，而不是切片搬运。
19. 评审这个 directing brief 是否可拍、可证、可测。
20. 为一个已有成片输出 keep/compress/remove 和下一版唯一改动。

## Should not trigger (20)

1. 把这段视频逐字转写出来。
2. 下载这个小红书视频到本地。
3. 用 API 现在发布这条小红书笔记。
4. 明晚 7 点提醒我发布。
5. 搜索 DeepSeek 最新版本号并给官方链接。
6. 这张图片 OCR 是什么？
7. 把 MP4 转成 GIF。
8. 给视频加嵌入字幕。
9. 把素材导入剪辑软件。
10. 查询我的小红书账号是否登录。
11. 点赞并收藏这个帖子。
12. 发布这篇微信公众号文章。
13. 把会议纪要整理成文档。
14. 查一下今天上海天气。
15. 修复这个 React 页面样式。
16. 读取这个 PDF 并逐页总结。
17. 只分析这条作者到底说了什么，不要给创作建议。
18. 检查这个素材有没有音轨。
19. 把 CSV 的点赞列求和。
20. 在 Notion 建一个排期数据库，不需要内容策略。

## Ambiguous routing checks

- “发布这条小红书内容”：若指 API/操作，不触发；若指发布前包装与实验，触发。
- “分析博主”：若只要事实重建，先用 reconstruction；若要原创账号/内容决策，再触发本 Skill。
- “复盘数据”：纯统计不触发；需要把数据转成编导诊断与下一版动作时触发。
