# 独立事实审计：6a79b3b5000000003301dd19

本审计只使用 `evidence/evidence-pack.json`、其引用帧、原视频与 SRT；未读取 run candidate、V0、observations、其他 corpus 或旧报告，也未进行外部事实核验。它只构造供后续 GATE evaluator 使用的独立分母，不评价任何 candidate。

## 原视频要完成的认知变化

视频试图让观众从“知道短视频是风口，但不知道如何赚钱”转变为：不要只把自媒体广告当收入来源，而要把自媒体看作已经提供渠道与广告的基础设施，自己解决“产品”这一环。产品可以有两条发现路径：向外观察风口受益者的需求，或向内把消费型兴趣加工为可售产品；找到产品后，再按服务型或资料型决定内容形式。

这是一个策略型论述，不是操作演示。视频内出现的市场趋势、客户画像、需求与产品机会都属于作者主张或建议；视频没有展示获客、成交、交付、回款或盈利结果。

## 关键事实骨架

1. 开头 0–1.2 秒插入多组高播放/互动数据，可见如 832.7 万、611.9 万、976.0 万浏览、2903.0 万浏览、1358.0 万浏览及多组点赞/收藏/评论数字。它承担社会证明，但视频没有建立这些数据的账号、帖子、统计时点、归属或与本方法的因果关系。
2. 2.806–8.957 秒的核心承诺是帮助普通人在自媒体平台找到自己的“生意”，不是 SRT 所写的“自己的声”。
3. 作者声称自媒体广告行业“江河日下”，品牌投放越来越少、中介返点越来越高。视频没有给数据来源；必须标为 author claim。
4. 核心模型是“生意 = 产品 + 渠道 + 广告”。作者认为平台已解决渠道与广告，观众需要解决产品；产品需同时满足“有东西卖”和“有人买”。
5. 方法一是向外找：先找买家、再找产品，服务已经在风口中赚钱的人。房地产缺资金资源、AI 缺技术被用来说明普通人难赚风口内部钱。
6. 游戏/陪玩例子形成一条明确但未经验证的推理链：打手和陪玩 → 年轻男性、熬夜、独居、点外卖 → 孤独与健康需求 → 线下社交、营养餐食。人物画像与需求不能写成已证事实。
7. 其他向外例子是：AI 开发者 → 发布会组织；电商主播 → 形象和化妆服务。
8. 方法二是向内找：视频先引用“最好的复利是培养一门生产型兴趣”，随后反转为“消费型兴趣也能产品化”。
9. 消费型兴趣例子是：刷短视频 → 一周热点简报 → 年长或忙碌且想做自媒体的人；打游戏 → 陪玩、代练中介、训练课；看电影 → 约会聊天素材包。
10. 结尾仍有核心知识：产品决定内容；服务型拍第一视角 vlog，资料型拍口播干货或图文。102.216–105.214 秒正确的自报身份是“人类最强编导”，随后说下期再见。

## 载体与冲突

视频不是“只有口播”。白板持续承担结构化信息，人物指向白板来锚定论述；顶部持续显示小红书环境、“人类最强编导（9.4–9.6 深圳线下课）”推广；开头另有独立指标拼贴。11 个技术镜头大多仍是同一白板场景，不能把 cut 当语义断点。

SRT 必须保留为原始层，但不能单独决定语义。至少有以下后果性冲突：

- `CUE-003`：“自己的声” vs 烧录字幕“自己的生意”。
- `CUE-004/005`：SRT 漏掉“品牌投放越来越少”的“少”，并破坏“做自媒体广告”的分句。
- `CUE-010`：“再找产品屋” vs “再找产品”。
- `CUE-020`：“脑定” vs “锁定”。
- `CUE-026`：“最好的腹地” vs 烧录字幕所支持的“最好的复利”。
- `CUE-032/033`：“消费情绪” vs “消费型兴趣”。
- `CUE-038`：“人类最常骗的” vs 品牌与烧录字幕“人类最强编导”。
- `CUE-001` 的“教子/教资”字词本身不可靠；只能确定画面确实展示了指标拼贴。

## 关键未知与负证据边界

后续评价必须奖励正确 abstention，而不是用常识补齐。关键未知包括：讲者真实身份；开头指标归属与方法归因；行业衰退主张的样本、地区和平台；客户画像和需求的调研依据；需求验证、付费意愿、竞争、定价、成本、利润；如何找到买家；产品包装、交付、复购与责任支持；平台/账号/地区/合规条件；案例是否真实执行和盈利；混合产品如何选择内容；线下课报名、价格与服务范围。

可以作出的负面陈述必须限定检查范围。例如：全片口播、烧录字幕、白板、插入画面与人物视觉均未展示完整成交闭环；但不能因此说“全片没有商业 CTA”，因为顶部持续存在深圳线下课推广。准确表述是“结尾没有口头关注、购买或报名 CTA，但全片有持续视觉推广”。

## Canonical challenge families

- Identity inversion：适用。面罩造型不等于真实身份；品牌名须用“人类最强编导”，真实人物未知。
- Literal failure/result signatures：不适用。没有 UI/产品执行演示；应审计的是“没有结果证明”。
- Opening/closing qualifiers and disclaimers：适用。开头指标、持续课程推广、结尾品牌与无口头 CTA 都不能漏。
- Opening-to-closing semantic relation：适用。社会证明暗示 → 方法教学 → 品牌收束，但指标归属和因果未知。
- UI progress/status：不适用。没有操作 UI；开头静态数字不等于可验证状态。
- Referent relations：适用。必须区分讲者、品牌、面罩角色、平台、课程、指标账号及各类目标客户。
- Edited chronology vs dependency order：有限适用。无真实执行过程；唯一明确策略顺序是“先找买家，再找产品”。
- Scoped negative evidence：适用。`audit.json` 列出 10 项有界 absence claims。
- Consequential carrier conflicts：适用。至少 8 项，多个会改变核心知识或身份。
- Technical segmentation vs semantic continuity：适用。白板与口播跨 11 个镜头连续。
