# 普通人如何在自媒体平台找到自己的生意

> 本文只重建视频内部内容，不验证作者的行业判断、客户画像或商业效果。文中的“作者认为/建议/声称”均是视频作者主张，不等于已经证实的事实。

## 这条视频真正要解决的问题

视频从一个矛盾开场：观众可能知道短视频是风口，却仍然赚不到钱。作者把问题进一步表述为“为什么你的财富匹配不上你的认知”，并承诺教普通人在自媒体平台找到自己的生意（00:01–00:09；KU-01）。

开场并非纯口播。最前面的约1.2秒叠放了多张短视频数据截图，可见832.7万、611.9万、976.0万浏览、2903.0万浏览、1358.0万浏览等数字（00:00–00:01；KU-02）。这些画面在剪辑上承担结果与权威暗示，但视频没有建立截图属于谁、统计口径是什么、是否真实，也没有证明这些结果由后文方法产生。

全片主要是一名戴红色蜘蛛侠风格面罩的人在白板前讲解。顶部持续出现“小红书”样式标记、圆形头像，以及“人类最强编导（9.4-9.6深圳线下课”字样（KU-03）。这只能说明可见造型和显示文案，不能确认人物真实身份、账号归属或IP授权。

## 为什么作者要把注意力转向“产品”

作者先给出一个行业判断：现在入局短视频、靠自媒体接广告，“这个行业简直是江河日下”；品牌投放越来越少，中介返点越来越高。因此，他认为2026年想赚钱，需要找到一门自己的生意（00:09–00:17；KU-04）。视频没有提供行业数据、平台范围、地区范围或样本，这一段应保留为作者主张。

随后作者给出生意公式：

**生意 = 产品 + 渠道 + 广告**

他的推理是，自媒体平台已经替创作者解决了渠道和广告，剩下最重要的问题是找到产品（00:15–00:22；KU-05）。他又把产品是否成立压缩成两个条件：

1. 你有东西卖；
2. 你的东西有人买。（00:21–00:25；KU-06）

这个框架有意简化了供应、成本、定价、交付、复购、合规和平台分发等问题；视频也没有告诉观众如何验证“有人买”。

## 方法一：向外找——先找买家，再找产品

第一条路径是“向外找”。作者建议先确定买家，再围绕买家寻找产品，并把它概括为赚“风口周边的钱”（00:25–00:29；KU-07）。

他把风口形容成“给普通人看，但是不给普通人赚的东西”（00:29–00:32；KU-08）。接着用两个例子说明进入核心机会的门槛：十几年前知道房地产是风口，却可能没有钱和资源；现在知道AI是风口，却可能没有技术。于是他的结论是：如果赚不到风口里面的钱，就去赚风口周边的钱，服务那些已经在风口里赚到钱的人（00:32–00:44；KU-09）。

这条路径的推理链是：

**先找风口里的获利者 → 理解并共情这批客户 → 描绘生活与工作状态 → 推断衍生需求 → 提出产品**（KU-10）

但视频只说“先找买家”，没有给出首批买家的实际获取路径。在24.665至64.860秒完整“向外找”区间内，字幕、烧录字幕、白板和指示动作都没有说明到哪里搜索、如何筛选名单、用什么话术联系、通过什么渠道触达或怎样跟进（KU-28）。这些步骤必须保持未知，不能由常识补成获客教程。

### 陪玩人群的例子

作者先声称“游戏是虚拟产品最好的生意”，陪玩行业赚到了大笔的钱。随后，他把打手和陪玩概括为男性、年轻、熬夜、独居、点外卖（00:44–00:54；KU-11）。

他由这些特征推断出孤独和健康需求，再提出两类产品：线下社交与营养餐食（00:51–00:59；KU-12）。这只是作者从画像到需求再到产品的推断；视频没有提供用户访谈、需求调研、付费测试、成交或效果证据。

### 另外两组“风口周边”服务

作者还给出两组简短映射（00:59–01:05；KU-13）：

- 给AI开发者做发布会组织；
- 给电商主播做形象和化妆服务。

它们共同表达的是：即使自己不做风口的核心业务，也可以向其中的获利者提供配套服务。但视频没有展示真实客户、订单、价格或交付结果。

## 方法二：向内找——把兴趣变成产品

第二条路径是“向内找”，也就是从自己的兴趣出发考虑如何赚钱（01:05–01:15；KU-14）。作者先提到常见的生产型兴趣变现说法，再提出本段的反转：在自媒体时代，消费型兴趣同样能做成产品、同样能卖钱（01:13–01:34；KU-15）。

作者用了三组兴趣—买家—产品映射来说明这个观点。

### 刷短视频 → 一周热点简报

刷短视频被作者称为“谁都会”的消费兴趣。他建议把筛选与整理结果卖给年龄较大、工作忙、想做自媒体但没有时间刷短视频的人，产品是一周热点简报（01:15–01:26；KU-16）。

视频没有展示简报样品、信息源、版权边界、制作周期、售价、交付或成交。

### 打游戏 → 陪玩、代练中介、训练课

作者把打游戏归为消费型兴趣，并建议把它转成陪玩、代练中介或训练课（01:26–01:30；KU-17）。视频没有说明平台规则、账号安全、能力门槛、价格或结果。

### 看电影 → 约会聊天素材包

作者把看电影也归为消费型兴趣，并建议整理约会聊天素材包，卖给想在约会过程中获得谈资的人；视频原话使用了“装逼”这一措辞（01:27–01:34；KU-18）。视频没有展示素材包、版权边界、定价或销售结果。

这三组例子只能说明消费兴趣可能被重组为服务、撮合、训练或资料，不能证明任何消费兴趣都一定能卖钱。

## 找到产品后，内容怎么拍

作者最后给出一个非常压缩的内容决策规则：“产品决定内容”（01:34–01:42；KU-19）。

- 服务型产品：拍第一视角vlog（KU-20）；
- 资料型产品：拍口播干货或图文（KU-21）。

作者自己称这是“最粗暴的两点”。视频没有讨论混合产品、平台差异、受众、更新频率、制作能力或内容到成交的转化路径。

## 白板、剪辑与结尾提供的额外信息

白板不是纯背景。中央可辨“如何在自媒体平台找到自己的生意”主题，左右两侧分别承载向外找和向内找，讲述者多次用笔把口播映射到相应区域，底部还有产品到内容形式的手写关系（KU-23）。不过大量小字被人物遮挡，且源视频只有720×1280，不能可靠逐字转录。

证据包把视频技术性地切成11个shot。切点前后定向检查显示，除开头数据拼贴外，画面持续是同一面罩造型、白板、房间和橙色家具，主要变化是人物姿态、遮挡和字幕（KU-24）。因此不能把11个技术shot写成11个语义场景或11次剪辑；隐藏剪辑仍无法排除。

最后约3秒，作者说“今天我们就说到这里”，自称“人类最强编导”，并以“我们下期再见”结束（01:42–01:45；KU-27）。这与顶部持续显示名相呼应，把本片收束为系列账号内容，但没有回到开场数据做因果证明，也没有展示业务执行结果。

## 视频没有建立什么

在0至105.215秒全时间线的字幕、1.5秒dense帧、5秒缺席审计帧和定向帧中，没有观察到以下内容（KU-25）：

- 行业趋势或客户画像的外部数据；
- 产品需求验证与付费测试；
- 首批买家的搜索渠道、筛选标准、名单来源、联系话术、触达方式与跟进流程（24.665–64.860秒机会窗口内未观察到；KU-28）；
- 产品制作、定价、发布、成交、交付、复盘；
- 所举产品的真实销售结果；
- 失败案例、反例、明确不适用人群或导致方法失败的条件；因此两条路径不能扩写成普适规则（全片机会窗口内未观察到；KU-29）；
- 线下课价格或视频内可执行报名控件；
- 开场截图与后文方法之间的因果证明。

这些是对所检视频内部载体的有界结论，不表示视频外一定不存在相关资料。

媒体包含AAC立体声音频，能量检查没有发现超过0.4秒的明显静音；但现有证据不能可靠区分背景音乐、环境声或音效，也不能判断其叙事作用（KU-26）。

## 一句话还原

这条视频给出的不是一个经过验证的完整创业流程，而是一张“先找到可售产品，再决定内容”的策略地图：向外，可以服务风口获利者的衍生需求；向内，可以把自己的消费兴趣整理成服务或资料。它提供了框架和例子，却没有提供市场验证、执行参数或成交结果。
