## 认知目标与真实边界

视频试图让观众从“Vlog 是流水账记录”转向“Vlog 是产品”：先理解用户需求，再兼顾讲述者所称的平台偏好，选择日常/挑战及软硬素材，用叙事和 IP 组织内容，最后用标题与 slogan 包装。

## 关键问题分母（15）

1. 开场承诺是什么？——新手、博主转型者或企业 IP 看完后也能把流水账拍成爆款 Vlog；这是讲述者承诺，不是已证结果。
2. 方法的前提是什么？——“拍视频就是做产品”，所以第一步看用户需求。
3. 三类用户需求是什么？——好奇、陪伴、造梦，各自带国外生活/环球旅行/小众工作，上学/实习/打工人/宝妈，高知小资/自由等例子。
4. 讲述者声称平台喜欢哪三点？——真实、反差、交互；平台身份与可靠年份未建立。
5. 反差如何定义？——预期的英国留学纸醉金迷，与实际“像流浪汉”生活的落差。
6. 交互如何定义？——让用户参与生活；画面示例包括秦思、萝卜乔乔。
7. Vlog 分类层级是什么？——顶层为日常型与挑战型；日常型内部再分叙事型和固定型，不能拍平成四个并列类别。
8. 硬素材是什么？——被说成题材自身就足够强，例子有一元横穿中国、徒步回家、少年创业、零元生存；夸张说法不是证据。
9. 分类之后的总论是什么？——不管类型，本质仍是做 IP；Vlog 被称为最立体展示 IP 的形式。
10. 打造 IP 的四个维度是什么？——刻板/标志性行为、做到极致的作风、个人风格、让用户多维度了解你。
11. “IP 立体”的唯一指标是什么？——观众了解你的音乐、书、电影、技能、穿衣风格等；这是主张，不是经过验证的量表。
12. “最值钱的部分”是什么？——slogan 与标题，并被说成决定“视频”的一生。
13. 标题机制是什么？——普通故事加莫名其妙的标题，讲述者声称会爆；案例只作说明，不能证明因果。
14. slogan 案例如何对应？——池早：“打扮得美美的出门上班了”；彪马野人：“欢迎收看我独自升级的一天”。
15. 结尾是否证明或明确兑现开场？——没有，只说今天讲到这里、重复“人类最强编导”身份并告别。
