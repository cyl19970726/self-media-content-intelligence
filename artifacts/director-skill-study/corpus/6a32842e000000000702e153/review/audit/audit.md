## 认知变化

视频试图让观众把“做 IP”理解为一套信任与情感机制：从认识到信任、从喜欢到爱上。随后按两类对象展开：广告变现博主通过 ID 与一致的人设增强粘性和种草效果；卖产品的企业主通过口播建立观点/权威/信任，通过日常内容增加立体感、亲和力和粘性。

## 关键问题基准

1. 中心命题是什么？——IP 被说成“从认识到信任、从喜欢到爱上”。
2. 内容由哪两个平行分支组织？——广告变现博主、企业主 IP。
3. 广告博主为何需要 IP？——增强粉丝粘性、提高种草率。
4. ID 的两条规则是什么？——记忆点/顺口，以及信息量。
5. 人设由什么组成，设计边界在哪里？——真实性格、作风、爱好、特长、身份、习惯、口头禅；可以设计，但作者明确说设计不等于造假。
6. 情侣博主案例说明什么？——可记忆标签、互动话题与双方人设互相强化；画面用 `xm/wyy`，两个人设标签清楚写作“养胃”“花呗兽”，与原始 SRT 的错误词形不能静默合并。
7. 人设设计原则与反例是什么？——可以增加、不能颠覆；`fjj` 事件被作者当成颠覆独立大女主人设的反例，但事件身份和真假未获视频内证明。
8. 喜欢与爱如何区分？——喜欢优点；爱上无伤大雅且不伤人的缺点。
9. 校园例子的机制是什么？——优秀男生因数学失利而落泪，引发心疼，作为“缺点/脆弱促成爱”的说明。
10. 企业主的定义和商业机制是什么？——以卖产品变现者；创始人 IP 被说成降低决策成本并带来“为这个人买单”的用户。
11. 创始人 IP 如何与企业文化相连？——作者用雷军/小米和于瀚/抖音高频发视频举例，但它们只说明作者的论证，不证明因果。
12. 企业主的两类目标是什么？——品牌影响力、直接转化；作者以两则不同规模企业的咨询轶事支持“通常由规模决定”。
13. 企业主的两种内容方向是什么？——口播立观点/权威/信任；日常内容增加立体、亲和与粘性。
14. 开头结果图证明和不证明什么？——可见小红书数据拼贴及约 3 万粉丝的“人类最强编导”主页；无法独立证明三天期限、归属、真实性或因果。
15. 可见身份与断言身份如何区分？——可见的是红衣、蜘蛛侠式面罩、白板、账号水印；真人身份、授权、账号归属及 `xm/wyy/fjj` 对应关系均未知。
16. 结尾做了什么？——完成“拍日常→粘性”分支、结束话题、自称“人类最强编导”、预告下期；没有回证开头“三天三万粉”。

## 高风险载体冲突

- CUE-001 的开头短语损坏；画面明确承担“展示成绩/资历”的 hook，随后才是“三天 3 万粉丝”。
- CUE-002 的“下次做 IP”应按画面理解为“下场做 IP”。
- CUE-016/018/021 的姓名和人设标签与画面层冲突：画面用 `xm/wyy`，并清晰出现“养胃”“花呗兽”；不得把 SRT 中冒犯性的“阳痿”或损坏的“花臂少”当事实。
- CUE-024/025 画面为 `xm这个fjj的事件曝出` 与“独立大女主人设”；SRT 的“福利金/独立案主”不可靠。
- CUE-045 画面写“于瀚”，SRT 写“宇浩”。
- CUE-056 画面写“立观点立权威立信任”，SRT 错成“利”。
- CUE-059 画面和重复水印均为“人类最强编导”，SRT 错成“人类最想编的”。

`audit.json` 共登记 10 项冲突，包含支持解释和仍未解决部分。

## 开头、结尾和全局关系

开头 0–2.567 秒连续使用两种结果载体：数据拼贴、约 3 万粉丝的个人主页。2.686–8.003 秒才进入“为什么做 IP”的主题承诺。中段 65.239–72.060 秒明确回到开头命题，随后用“优点/缺点”深化“喜欢到爱上”。

结尾 154.552–161.930 秒完成企业主第二个内容方向并常规收束。它与开头有账号身份呼应，但没有再次展示或验证“三天 3 万粉丝”。这是 opening↔closing 关系，不能只靠 cue accountability 代替。

## Scoped absence claims

在注明的时间范围和载体内：

- 全片没有软件操作或逐步执行演示；这是观点型讲解，不是程序型教程。
- 全片没有独立测量来证明 IP 对涨粉、粘性、种草、信任、决策成本或销量的因果效果。
- 全片未明确给出价格、购买链接、服务进入步骤或支持责任边界。
- 案例、事件、创始人例子和咨询轶事没有展示来源引用或外部核验。
- 没有失败态 UI 或 before/during/after 操作链；仅开头出现结果态截图。
- 最后两种内容方向没有给出精确频率、制作流程、预算或成功阈值。
- 结尾没有回证开头的三天三万粉结果。
- 20 个技术 shot 不等于 20 个语义场景；开头两段插图后，主体持续为同一蒙面讲者、同一房间与白板，仅有跳切和构图变化。
