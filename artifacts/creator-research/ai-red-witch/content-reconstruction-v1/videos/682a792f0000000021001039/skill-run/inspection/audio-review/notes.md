# CAR-08 非语音音频有界听检记录

检查对象是源 MP4 的完整 AAC 立体声音轨（44.1 kHz，约 33.79 秒）。音轨按冷开场、首页/文章/指令、排队转场、编辑器与 Labubu 结果、白鸭结尾五个互斥窗口分别提取；另以全轨单声道、左右声道差分、静音检测、相邻谱差和两种本地语义音频分类交叉核查。详细数值、路径和限制见 `audio-review.json`。

## 分段记录

- 0–3.233 秒，冷开场：女声旁白下有持续的轻快电子/器乐音乐床。开头约 0.115 秒之后没有达到 -35 dB/0.08 秒的完整静音。未能隔离出可归因的插入片原声。
- 3.233–16.733 秒，首页/文章/类型指令：同类背景音乐和旁白持续，音乐跨过页面与文章切换。约 9.965–10.095 秒只在 -25 dB 阈值形成短低能量谷；音乐仍覆盖，不能写成全轨停顿。
- 16.733–17.233 秒，排队/UI 转场：音乐未完全停止；有短促 click/tap/impact 类瞬态线索，17.233 秒附近谱差较强。它可能是 UI 或剪辑转场声，也可能来自相邻语音/音乐，不能当作按钮点击或生成完成证据。
- 17.233–30.533 秒，编辑器与 Labubu 结果：旁白和音乐床继续。约 18.0–19.7 秒有 ding/chime 类短音效线索；地图/门店段没有可可靠隔离的第二条配音或独立原声。提示音属于项目预览还是外层后期仍未知。
- 30.533–33.767 秒，白鸭结尾：音乐与旁白延续，约 32.3–33.6 秒有 ding/beep 类短音效线索。30.533 秒视觉切换附近音色变化增强但无静音；声音连续不等于项目同源。

## 可写入重建的结论

可以确认的声音包装是：贯穿主要时间线的轻快电子/器乐背景音乐床，以及三个短音效机会窗（排队转场瞬态、编辑器开头提示音、结尾白鸭提示音）。音乐跨越主要视觉剪切，承担把营销蒙太奇连接成连续观看体验的作用。

继续保持未知的部分是：音乐曲目、作者、许可；三个短音效究竟属于 UI、外层后期还是插入片原声；地图/门店和白鸭素材是否自带独立配音或原声；任何声音是否由 agent 自动生成。分类器对编辑器提示音窗和白鸭结尾的“插入片原声”候选较高，但没有隔离音轨，不能据此归因。

## 防错规则

背景音乐连续只能证明混音层跨剪切延续，不能证明画面连续录制、按钮被点击、生成完成、导出成功，也不能证明 Labubu 与白鸭属于同一项目。短促 click/ding/beep 只有在声源层被隔离或 UI 动作同步可见时，才能升级为具体 UI/素材原声证据。
