# 《天塌了！教你用Ai做海报，只要10秒》内容重建

## 一句话结论

视频真正给出的是一条被剪辑压缩的演示链：在烧录字幕称为“扣子”的界面里找到“营销海报生成”，按“风格+标题+小标题+日期+署名”组织描述，页面显示 2:3 等输入状态，随后画面从提示词切到短暂加载态，再切到圣诞海报结果。作者多次声称“不到10秒”、免费、中文没有崩、足以应付大部分基础设计；但视频没有连续计时、完整操作链或复现条件，而且示范输入日期“2024/12/3”与结果日期“2024/12/24”不一致。

- 15.52—17.72 秒：烧录字幕写“我们来到扣子”，界面出现“营销海报生成”应用卡。
- provided SRT 同段原文写的是“coz”，两种载体冲突。这里保留 SRT 原文，但以可见烧录字幕记录中文界面读法，不外推二者的外部品牌关系。

## “不到10秒”：主张与证据必须分开

作者在 5.24—6.72 秒第一次称“每张图只用了不到10秒”，在 25.68—28.72 秒又两次强调“不到10秒”。这是清晰的作者主张。

视频中的可见计时证据却只有：

- 约 26.85 秒仍是提示词画面；
- 约 26.95—27.5 秒是白色加载态；
- 约 27.6 秒切到结果；
- evidence pack 在 26.9 和 27.533 秒附近记录到技术画面边界。

因此，成片里“加载画面不到一秒”只说明剪辑后的片段长度，不能证明真实生成少于10秒。全片没有连续秒表、明确起止标记或不间断录屏，也没有说明计时是否包含打开工具、写提示词、排队、重试、挑选、导出或后处理。

证据：`CUE-003`、`CUE-012`、`CUE-013`、`TARGET-0049`—`TARGET-0055`。

## 结果自身出现了文字不一致

输入提示词要求日期 `2024/12/3`，首个结果显示 `2024/12/24`。这不是 OCR 自动修正：两边都经过原帧人工核对。随后 Logo/导出段硬切到另一张红发人物圣诞海报，其日期行也可见重复斜杠、数字等紊乱字形。

所以视频可以证明“展示了若干含中文的海报”，但不能证明中文总是不崩；本视频自己的结果已经给出日期不遵循输入的反例。

证据：`TARGET-0044`、`TARGET-0055`、`OCR-00622`、`TARGET-0073`。

## 复现这条教程仍缺什么

在完整 0—48.667 秒视频、SRT、烧录字幕和 UI 中，没有可靠建立：

- 具体访问 URL、客户端或网页端；
- 版本、登录/账号、地区；
- “免费”的范围、额度和持续时间；
- 模型、分辨率、生成数量、随机性参数；
- 参考图与标签的必需性或选择状态；
- 真实生成耗时和计时口径；
- 修改、高清化、Logo、模板复制、开发应用的完成步骤；
- 导出文件格式、分辨率、存储位置；
- 视频外后处理；
- 失败条件、重试次数、样例挑选和成功率。
- 实际录制日期、平台发布日期、界面实际运行日期，以及画面属于当时实时界面还是历史/回放录屏。原 MP4 没有 `creation_time`；海报内的 `2024/12/3`、`2024/12/24` 是内容字段，证据包生成时间是处理时间，三者都不能替代录制或界面运行日期。

因此，视频足以让观众理解“去哪里、写什么、期望看到什么”，但不足以仅凭这一条视频稳定复现作者宣传的速度、免费条件、文字可靠性或完整交付流程。

## 非语音音频

非语音音频已从原 MP4 的 AAC 轨实际分段检查，不再以静帧、字幕或“有音轨”代替音频证据。五个无缝时间窗覆盖 0—48.667 秒：

- 开场 0—6.72 秒：口播下方持续检测到背景音乐；没有可靠分离出独立的一次性音效。
- 质量展示/教程承诺 6.72—15.52 秒：音乐继续保持；段末出现短促过渡/敲击类候选，但精确身份不稳。

- 加载/结果/调整 25.68—36.32 秒：音乐再次持续检测到，但强度有变化；没有可靠建立独立的结果提示音或导出音效。
