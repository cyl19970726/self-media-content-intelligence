## 一句话还原

- 看前：观众可能认为好看的 HTML Slides 需要编程基础或复杂设计能力。
- 看后：观众获得一条低门槛流程：在 AnyGen 选 Frontend Slides 模板，用白话输入内容，生成后用评论批量修改，再通过链接分享或导出；模板质量来自长期收集视觉参考。
- 认知变化：从需要编程转向模板+白话生成
- 认知变化：从生成即结束转向评论式批量修改
- 认知变化：从工具技巧转向日常建立视觉参考库

**论证结构**

- 论点：低门槛生成好看 HTML Slides 的上限主要来自模板和视觉参考，而不只来自提示词。
- 条件：模板与内容匹配；参考使用合法；AI 能保持信息正确；用户复核排版与交付

未知：工具准确身份；参考与输出相似度；版权/字体/肖像授权；模板许可证
