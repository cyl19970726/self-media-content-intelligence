# Session Forensics 完整剪辑 Spec V4

## 0. 本版结论

这条片不使用一个从头到尾不变的“上内容、下人物”模板，而使用一套由内容意义驱动的镜头状态机：

- 人物负责提出问题、作出判断、解释边界和完成收束；
- 内容负责证明数字、流程、真实操作与结果；
- 重要证据短暂全屏，人物可以退场；
- 每次画面切换必须对应认知任务变化，不能只为制造热闹；
- 默认保持“上方内容、下方人物”，但人物和内容面积会随信息价值变化。

当前 V2 口播粗剪为 **124.4 秒**。本版以完整产品解释母版为目标，不再强行压到 60 秒；后续可从同一母版派生传播短版。

## 1. 参考研究：AI 红发魔女真正可迁移的剪辑语言

本 Spec 不是只看一张截图，而是对照现有重建报告和联系表中的四类完整视频：

1. **工具地图，16.6 秒**：每 1.5–3 秒切换一个“工具名 → 可见能力/结果”，约 32.6 切/分钟。人物承担快速报幕，结果承担理解。
2. **效果展示，22.5 秒**：先连续展示结果制造欲望，再给最小输入流程，最后回到效果，约 16 切/分钟。
3. **任务解法，29.1 秒**：失败结果 → 一句方法 → 操作过程 → 成功验证，约 10.3 切/分钟。
4. **新品深度解读，87.9 秒**：模型定义 → 多组样片证明 → 原理/训练信息 → 应用推演 → 行动建议，约 10.9 切/分钟。

### 共同规律

- **先看结果，再听解释**：开头先让观众看到失败、奇观或最终产物，工具名和原理可以后置。
- **一镜一个价值单位**：当前说哪个工具、步骤或证据，画面只保留这一件事。
- **人物不是永久主画面**：人物可以全屏、下方窗口、圆形画中画或暂时消失；面积由证据价值决定。
- **全屏不是转场装饰**：全屏只给决定性结果、关键操作、来源建立或情绪高潮。
- **真实界面与结果交替**：界面回答“怎么做”，结果回答“为什么值得做”。
- **字幕是导航，不是第二篇文章**：字幕短、粗、靠近当前视觉焦点；画面中已有同样文字时不重复堆叠。
- **视觉切换跟随语义阶段**：切换通常发生在工具、步骤、主张或证据对象改变时，而不是每个逗号都切。

### 不照搬的部分

- 不复制她的红发、人物设定、房间、绿色/棕色底板或工具卡外观；
- 不复制“一键、任何、无限、免费”等没有条件的绝对化表达；
- 不用结果蒙太奇冒充完整操作因果；
- 不用高切换率掩盖证据不足。

## 2. 本片唯一叙事任务

观众看完后必须能复述：

> Session Forensics 不是让执行 Agent 再聪明一点，而是让一个外部 Session 把自我叙事与物证放在一起，寻找目标、动作和结果之间的裂缝，再给出继续、干预、升层或停止的动作。

叙事链固定为：

`异常活动量 → 真正危险 → 错误自审 → 执行/审计分权 → 叙事流/物证流 → 外部全局视角 → 三条真实发现 → 使用流程 → 回传与周期复审 → 边界结论`

## 3. 六种画面状态

### H｜Hook Split：结果钩子上下分区

- 上方内容 56–62%，下方人物 32–38%；
- 上方出现一组强证据，人物负责说出反差判断；
- 适用于开头数字与“进程保姆 / 唯独没有写一行代码”；
- 不同时展示四张数据卡，数字按口播逐项替换或累积。

### P｜Presenter：人物主导

- 人物 52–68%，内容 20–36%；
- 只保留一句短判断或一个简单符号；
- 用于“真正危险”、个人判断、边界与结尾；
- 人物变大是认知停顿，不是为了填满画面。

### S｜Split Default：默认讲解

- 上方内容 62–68%，下方人物 28–34%；
- 适合简单关系、角色定义和三到四步解释；
- 上方一次只呈现一个关系，不显示完整复杂 Dashboard。

### E｜Evidence-led：证据主导

- 上方内容 76–82%，下方人物 14–20%；
- 用于数据、双流对质、真实 UI、流程依赖和案例发现；
- 人物仍在下方中间作为连续性锚点，但不能占用证据阅读面积。

### F｜Full-screen Proof：全屏证据

- 内容 90–100%，人物 0–10%；
- 每次通常 0.8–2.5 秒；
- 用于 40MB 报告来源、复制 Session ID、报告生成结果、关键失败签名；
- 全屏后必须回到一个更简单的解释状态，不能连续堆长图。

### R｜Result Hold：结论/结果停留

- 画面只保留一个结果或一个问题，人物可隐藏或后半重新出现；
- 末尾保留 0.8–1.2 秒静止，便于截图、收藏和理解；
- 本片结尾文字为：`它不能保证结果，但能让偏离更早暴露。`

## 4. 人物窗口规格

- 人物固定在下方中间，不在左右来回跳；
- 采用真实矩形环境背景和 28–40px 圆角，不抠像；
- 默认窗口宽约 92% 画布，H 状态高约 34%，S 状态约 30%，E 状态约 18%；
- 保留完整头顶、下巴和肩线；缩小时重新检查左侧植物、吉他、百叶窗和鱼缸是否重新露出；
- 开场、判断和结尾可以切人物全屏，但必须是完整语义句，不在半句中切脸；
- 人物窗口与上区属于同一视觉环境：统一暗底、边缘高光、阴影方向和圆角，不使用厚霓虹框。

## 5. 上方内容规格

### 真实证据优先级

1. 可核验的聚焦录屏；
2. 报告或截图的最小 ROI；
3. 从真实数据重建的单焦点图；
4. 解释不可见机制的 Motion Graphics；
5. 纯装饰画面。

### 信息密度

- 一屏一个问题；
- 一个证据镜头最多一个标题、一个核心数字/动作和一个来源角标；
- 完整桌面只用于 0.8–1.5 秒定位，随后切到按钮、输入框、Session ID、报告结果等 ROI；
- 360×640 审片下：核心数字 ≥32px，标题 ≥24px，正文 ≥16px，来源 ≥12px；
- UI 小字如果无法达到 16px，就重新裁 ROI 或改成自制解释卡，不能硬塞。

## 6. 字幕与画面文字

- 字幕固定在上下区交界附近或稳定的下方安全区；
- 每卡 8–16 个汉字，优先一行，必要时两行；
- 字幕只记录口播，不重复上方已经完整呈现的数字和标题；
- 关键词可使用单色高亮，但每卡最多一个重点；
- 必须人工修正：`Agent`、`进程保姆`、`Session Forensics`、`Session ID`、`Gate`、`Compaction`、`有界下钻`、`升层`；
- “唯独没有写一行代码”作为作者判断保留，但其附近不同时展示“文件确有改动”的统计，以免声画互相否定；后续证据段再解释活动与目标闭合的区别。

### 需要新制作的解释型视觉

1. 开场异常活动量与“进程保姆”状态变化；
2. 执行者自审闭环；
3. Executor / Auditor 分权关系；
4. 叙事流 / 物证流与裂缝；

8. 回传与三小时复审的闭环。

这些视觉共享同一视觉语言，但不使用同一个万能卡片模板。

## 9. 动效节奏

- 本片为深度解释，不追求工具地图的 30+ 切/分钟；目标 **11–15 次有效视觉切换/分钟**，约 23–31 次主要变化；
- 视觉变化必须在关键词后 8–15 帧内响应；
- 普通缩放/替换 12–24 帧；
- 决定性证据使用硬切或 6–10 帧短过渡；
- 一句话只有一个主运动，不能人物缩放、证据入场和字幕跳动同时发生；
- 完整语义段内尽量不切人物源；A-roll 接口用上方证据遮挡。

## 10. 声音

- 人声是 anchor；背景音乐是 follower，自动避让人声；
- 当前源平均响度较低，先做保守增益和轻度人声清理，不重制声线；
- 每个录音环境抽样试听，避免水下感、金属感、吞尾音；
- 所有语音硬切完成后统一保留 4 帧微交叉淡化；
- 背景音乐选择无歌词、克制的技术纪录感，不使用夸张“赛博科技”音色；
- SFX 只用于数字落点、裂缝出现、报告到达和结尾停顿，不能每张卡都响。

## 11. 完整制作流程与 Gate

### Gate 1｜A-roll 已锁定

- 124.4 秒口播逻辑完整；
- 保留“唯独没有写一行代码”；
- 仅建议补录一句：`最后，它不会只给一份报告，而是明确告诉你：继续、干预、升层，还是停止。`
- 若不补录，现有“继续干预、停止生成”等口误只能通过字幕弱修正，声音本身仍不够清楚。

### Gate 2｜先验收一个代表画面

- 用 0–12.9s 开场制作第一套 H 状态；
- 必须真实包含上方证据、下方人物、字幕和最终手机比例；
- 用户确认视觉语言后，才批量制作其他 Motion Graphics。

### Gate 3｜四种核心状态验收

- P、S、E、F 各导出一张 1080×1920 和一张 360×640；
- 验收人物裁切、文字大小、证据单焦点和字幕安全区；
- 任一状态在手机上不可一眼理解，则回到布局，不继续堆素材。

### Gate 4｜真实证据链先完成

- 先放复制、粘贴、发送、报告出现和回传；
- 再补不可见机制的 Motion Graphics；
- 不允许用解释动画替代可用的真实操作证据。

### Gate 5｜静音理解测试

- 静音看完整片，观众应能复述当前处于：问题、错误解法、核心思想、机制、案例、使用、结论中的哪一段；
- 如果只能看见“很多漂亮卡片”，但不知道证据链，判定失败。

### Gate 6｜声音与字幕

- 修正术语；
- 完成人声处理、音乐避让、转场微交叉淡化；
- 字幕不能遮嘴、眼、按钮和关键数字。

### Gate 7｜手机与隐私验收

- 360×640 检查所有稳定帧与布局切换前/中/后三帧；
- Session ID、用户名、邮箱、绝对路径、密钥和未发布项目必须脱敏；
- 外部材料保留最少必要引用与来源，不暗示跨产品同根因；
- 最终导出后再次检查，不以时间线预览代替成片复核。
