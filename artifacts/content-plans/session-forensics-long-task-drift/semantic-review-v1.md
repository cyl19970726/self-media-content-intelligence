## Required fact corrections before any rewrite

1. **“8 次”现在误读。** Metrics 的 `recurring_asks[0]` 有 8 个 `members`，但只有 7 个相邻 `pair_verdicts: "restated"`。所以“我重新说了八次”（候选第 104 行）暗示“在初始要求之外又重复八遍”，证据不成立。可说：`这个重复诉求簇共有 8 次表达；相邻表达中有 7 次被判为重述。` 也不可把 8 条说成文字完全相同。
2. **“3 小时 / 0 改动”被拼接成了一个未经同一来源支持的事实。** #31351 支持“约 3 小时反复自动压缩、没有实际进展、约消耗 30% 用量”，未建立“0 个文件改动”；#27588 支持“2–4+ 小时、没有编辑文件”。候选第 88–90 行、封面第 218–222 行、线框 E 卡把两者混成 `3 小时 / 0 个文件改动`。二选一：使用 #27588 的 `2–4+ 小时仍未进入文件编辑`，或使用 #31351 的 `约 3 小时反复压缩、没有实际进展`，并把来源编号放在同一张证据卡上。
3. **本病例的计数正确，但解释必须收窄。** `/tmp/session-019ff003-metrics.json` 直接支持 11,396 行、1,430 `exec`、336 `wait`、16 次 compaction、102 次 patch、39 个文件；这些是活动计数，不能推导为“0 产物改变”或自动证明“目标没有任何推进”。候选的 102/39 没有进入视频主叙事，导致“忙但无进展”的判据没有可见定义。
4. **机制句越过证据边界。** “一旦 Agent 接到目标，它就进入执行者视角”“为了证明自己没错”以及“失败尝试会污染后面的判断”（第 108–112 行）是拟人化因果断言，不是当前会话或外部来源可直接证明的观察。可保留为标注了“本会话的一种失败链 / 工作假设”的图，而不能当普遍机制讲述。

### G1 Evidence fidelity — FAIL

正面证据：metrics 精确支持本会话的 11,396 / 1,430 / 336 / 16；#27588、#31351、#14120、#5957 都是“用户报告”的恰当类型，Claude 官方页确实说明 `Autocompact is thrashing`：自动压缩成功后，大文件/工具输出多次迅速填满上下文，Claude Code 为避免无进展循环而停止重试。

失败证据：

- 见上文“3 小时 / 0 改动”的跨来源拼接。
- 第 104 行把 8 个簇成员误说成 8 次额外重述。
- 第 108–112 行将未验证心理和因果关系说成确定机制。
- 0–4 秒的 `FILES CHANGED 0` 虽声明“概念动效”，但与同屏“运行 03:00:00”组合，极易被理解成真实外部案例；必须在卡上标 `概念示意，非真实截图`，且不要和来源证据卡混用。
- “答不出来，就该停”（第 128 行）把一个诊断启发式升格为普适决策。复杂任务可能在等待外部构建、人工批准或生成；应改为“答不出来，先暂停新增工作，审计后再决定继续/分拆/停止”。

**修改项：** 逐张证据卡显示 source ID、claim class（观察/用户报告/工作假设）和边界；用一套来源支持一个数字组合；将机制图改成“本会话可见的失败链（推断）”，加入替代解释。

### G2 Promise closure — FAIL

标题、封面和首帧的“认真空转”张力一致；主体也给出“活动不等于目标进展”的真实病例，方向正确。但交付承诺没有收口：34–51 秒只报出“定位→量化→下钻→对质→纠偏”的名称，观众并不知道怎样以该五步判断一次任务；51–60 秒又把真正的“完整演示”移交给一条尚无生产保证的下一集。`收藏下一条`不是可执行 CTA，且“答不出来就该停”过度承诺。

**修改项：** 本条完成一个最小闭环：给出同一病例中“目标/物证/结论”的一张可读对质卡，行动改为“把过去十分钟的目标产物写成一句可验证状态；没有状态就先审计”。下一集承诺只在已有演示素材、发布日期和主题时保留，并在结尾说明其新增价值。

### G3 Executability — FAIL

线框和第 141–192 行的布局规则对“人物在下、内容在上”很具体：P/S/E/F 的比例、时间线、ROI 裁法、最小字高、转场时长、四段口播不碎切，都直接回应了原始痛点。它解决了“怎么裁”的方向，但还不可交给剪辑执行：

- 没有逐段写出将使用哪一个原始口播段、保留源范围、接口的画/声音画、何时切哪一个 ROI、各卡的精确文案与 source ID。
- “在最终 360×640 预览裸眼可读”有标准，没有实际预览验收截图/检查人和不通过后的返工动作。
- 第 182 行称“三张原帖证据卡”，却列“2–4 小时、3 小时、thrashing”，但并未分别指定 #27588/#31351/Claude 官方页，且后者不是“原帖 issue”。
- “下一条完整演示”无排期、素材、负责人或 fallback。
