## 0. 成片定义（一句话）

一条对表红发魔女 badclaude 条（`69d65879`）的口播片：
**亮色底 + 真实截图当主体 + 手绘马克笔圈注 + 人物大而生动 + 短字幕 + 语义点硬切**，
讲清两个真痛点，然后把 Session Forensics 作为解法卖出去。

## 1. Owner 定义的两个真痛点（口播开场的地基，不许再漂）

用 AI 对一个目标干一两天之后：

1. **简单任务被它自加的重验证带偏**：明明是小事，它自己加 gate、过度验证、过度 CI/CD，
   目标偏移——"改个按钮文案，它给我修了一天城墙"。
2. **长任务里你是瞎的**：等待过程中不知道它执行到哪了；一天过去，交付很烂——
   大量验证动作，最后只写了 100 行代码。

解法钩子：这两种都是 session-forensics 能查的，而且 skill 就自带（"你本来也有"）。

## 2. 参考的「丝滑」到底是什么（帧级反推，不是感觉）

对照 badclaude 条抽帧，她的切换丝滑来自四个机制，缺一个就会变成我们旧版那种"卡片 PPT 感"：

| 机制 | 她怎么做 | 旧版怎么错的 |
|---|---|---|
| **一屏一物** | 每帧只有一个知识对象（一张截图/一张便签/一个大字标题） | 一卡 3 个信息块 + 三列小字，眼睛没有落点 |
| **切换踩语义点** | 画面变化只发生在口播换对象的瞬间，句内不动 | 静态卡挂 10 秒 + 字幕换了画面不换（声画错位） |
| **单一入场运动** | 全片只有几种干净的运动：手绘线从头画到尾、便签轻弹入、截图硬切 | 无动效层次，元素要么全静止要么同时动 |
| **硬切靠内容差异造节奏** | 真实截图之间直接硬切，明亮底色统一所以不跳戏 | 想用转场特效补节奏，但底色全暗、内容全同质，切了也感觉没切 |

⇒ 丝滑 = 内容密度低 + 切换踩点 + 运动语言统一。**不是**加更多动画。

## 3. 总流程（六阶段，带验收闸）

```
P0 痛点素材池 ──┐
                ├─→ P1 逐字稿(三列合一) ─→ P2 样板段验收 ─→ P3 录口播 ─→ P4 剪辑 ─→ P5 成片验收
（可并行进行）──┘         ↑你定稿              ↑你验收丝滑          ↑你录        我做      ↑你验收
```

### P0｜痛点素材池（我做，今天可完成）

- **X 高热吐槽帖**：gork cli / ego-browser 搜"等了一天 / goal drift / 过度测试 / esc to interrupt /
  compacting"类帖子，只收有热度的，截图存 `pain-evidence/`（学她"昨天刷到一个……"的开场用法）。
- **自有真物证**：40MB 案例数字卡素材（2,979 Exec / ≈1,868 Wait / 16 Patch）、真实等待录屏（倍速）、
  `git diff --stat` 一天→百行截图。
- **重演录屏**（半天）：真实 agent 把简单任务做出一堆 gate/CI 文件的文件树录屏。
- AI 生成只保留 1–2 个情绪梗位（插画/表情包），不做证据画面。

### P1｜逐字稿（我出初稿 → 你改口气 → 定稿）

**格式：三列合一表，一行 = 一个语义拍**，这是全片唯一剧本，录制、剪辑、动效都从它派生：

| # | 口播句（≤20字，口语） | 画面（一屏一物） | 切换动作（单一运动） |
|---|---|---|---|
| 1 | （示例）我让它改个按钮文案 | 真实 issue 截图 | 硬切入 |
| 2 | 它给我修了一天城墙 | 文件树疯长录屏 | 马克笔圈住新增文件 |

结构骨架（句式全部对表她的口语体，杜绝定义句）：
**热帖/倒霉事开场 → 痛点1（城墙）→ 痛点2（瞎等一天）→ 一句"让它自查没用" →
一句心智模型（它嘴上说的 vs 实际干的，对着找裂缝）→ 真实案例数字 → 用法（复制 session id，一句话）→
收尾（不保证结果，但偏离更早暴露）**。

### P2｜样板段验收（我做 0–12s 完整样板 → 你只验这一段）

- 含开场 2–3 次切换的完整动效、真实截图+手绘标注、字幕、人物窗。
- 你验收的就一个问题：**这 12 秒像不像她、丝滑不丝滑**。不过，就回炉，不往下走。
- 这一闸不过，禁止批量生产任何后续画面（Codex 就是跳了这一闸）。

### P3｜你录口播

- 按定稿逐字稿分段录（每段一个语义拍群，8–18 秒），提词器贴镜头轴，每段 2 take。
- 录完我当场做**录音 vs 逐字稿 diff + 整段过耳**，当场告诉你哪句需要重来——重录窗口只开这一次。

### P4｜剪辑（我做，新 session 用 ChatCut 插件）

顺序不可倒：A-roll 过耳确认 → 上区画面（先真实截图后手绘动效）→ 字幕 → 音乐音效 → 360×640。

### P5｜成片验收（你）

静音测试（不听声音能否知道在讲哪件事）+ 丝滑检查（每次切换前/中/后三帧）+ 手机可读 + 脱敏。

## 6. 内容结构（从她两条「痛点→解法」样本逐秒反推，不是拍脑袋）

### 样本 A｜6801c075「deepseek乱码一句话解决」28s（工具技巧型）
场景带入 2s → 痛点反问共鸣 3s（"是不是这样格式全乱"）→ 承诺解法 2s（"教你一个神技立马解决"）
→ 操作演示 15s → 结果验证 4s → 情绪收尾 2s。
规律：痛点只占 5s，演示占大头；痛点用**反问句**，解法承诺**立刻**给。

### 样本 B｜69424c0d「熬夜打工人健康搭子」105s（痛点→产品种草型 ← 我们就是这个）
1. 0–7s **别人的真实事件开场**（19 岁学生脑梗新闻）
2. 7–10s 自我代入（"这不就是我吗？"）
3. 10–31s 痛点堆叠成第一人称具体场景（"你是不是跟我一样，凌晨一点…越看越焦虑"）
4. 31–38s 转折引入产品（"直到最近我体会到一种完全不同的方式"）
5. 38–73s **机制用一次具体交互还原**（我说累→他先问睡眠→追问咖啡几杯→告诉我不加量就行）——不是功能定义！
6. 73–89s 第二特性 + 价值升华（"你已经在慢慢变好"）
7. 89–96s 信任背书 + 边界（"只提供参考，绝不制造恐慌"）
8. 96–105s 人群共鸣收尾 + 开放式问题 CTA

### 我们的结构（对表样本 B，逐段映射）

| 时间 | 对应她的段 | 内容 |
|---|---|---|
| 0–8s | 真实事件开场 | 42h 热帖截图+圈注："刷到个帖子，Codex 连跑 42 小时，建的东西和他要的完全不同" |
| 8–15s | 自我代入+痛点1 | "这不就是我吗？我让它改个小东西，它给我造了 50 个文档 80 个测试"（热帖数字+自己倒霉事） |
| 15–25s | 痛点2场景堆叠 | "你是不是也一样：它跑着，你盯着 esc to interrupt 干等，它到哪了、偏没偏，你全瞎" |
| 25–33s | 转折引入 | "问题不是模型笨——它一直在动，你就以为它在推进。后来我给它配了个法医" |
| 33–60s | 机制交互还原 | 一次真实审计过程：复制 session id → 拉完整历史 → 不听它怎么解释，只看它真正干了什么 → 等待 1800 次 / 版本号涨结论没变 / 小改动全量验证 →"它在认真空转" |
| 60–75s | 动作输出 | 不给论文，给四个字：继续/干预/升层/停止 + 报告发回原 session（真实录屏） |
| 75–85s | 价值升华+边界 | "它不能替你保证结果，但能让偏离更早暴露" |
| 85–95s | 收藏收尾+开放问题 | "你家 agent 干过最离谱的空转是什么？" |

对应 skill 设计思想的映射（口播里不用术语，画面上可以出现）：
叙事流 vs 物证流 = "不听它怎么解释，只看它真正干了什么"；B 类裂缝 = "它自己原理上看不见"；
GB→KB→下钻 = "40MB 历史压成几个数字再钻进去"；四动作终点照搬。
