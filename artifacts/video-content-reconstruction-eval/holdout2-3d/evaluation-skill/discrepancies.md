# Holdout2-3D Discrepancies

## Candidate 与独立 audit 的差异

### Candidate 补出的有效细节

1. **两套 UI 被正确拆开。** 分屏编辑界面与单头三维生成界面的视觉结构、控件和时间位置不同；candidate 明确说二者关系未知，没有把它们拼成一个产品。
2. **英文 prompt 被识别为输入条件。** 3.8、8.4、14.2 秒分别可见老年男性、闭眼老年女性和闭眼红胡子年轻男性提示词。这直接限制了“只靠画几笔”的更强说法。
3. **`KRE` 只作为残片。** candidate 没有凭视觉相似性补全品牌。
4. **Download 缺口表述更精确。** 单头 UI 明确有 `Generation successful!`、`Refresh` 和 `Download`，因此不能说“没有下载控件”；真正缺失的是 Generate/Upload/Download 点击、文件落盘、输出检查和跨 UI 桥接。
5. **身份与授权边界更完整。** 外层账号/平台/栏目没有被当成工具品牌，结尾人物身份、素材来源、许可和生成归因全部保持未知。
6. **结尾环境与视觉参照被保留。** 至少四个头部主体、格架式环境，以及老年女性前后相似所形成的视觉回环都有记录，但没有升级为同一资产证明。

这些差异不表示 ground truth 错误；它们来自 candidate 的高密度目标帧和 UI 放大复核，且经本评估独立看帧确认。

## Candidate 的实际问题

### 1. KU-017 标题过度断言非语音音轨存在

证据只证明视频有 AAC 音轨且全片有音频活动。SRT 只覆盖语音也不能反推出剩余信号必然是音乐或音效。正文已经正确写成“无法可靠分离，具体作用未知”，但标题仍形成 1 条无依据正面断言。

建议把标题改为“音轨有持续活动；非语音内容及作用未知”。

### 2. 一个低影响 UI 值未单列

7.5 与 12.0 秒单头 UI 的 `Mesh` 字段里可见近似 `3DAISTUDIO-V1` 的值。candidate 记录了 `Mesh` 标签但未记录这个值。由于它看起来更像模型/预设值，不能据此确认产品名或版本；遗漏不改变关键结论，也不形成新的未守载体或关系。

## 无差异的高风险项

- 两套 UI 未被错误合并。
- 英文 prompt、`KRE` 残片、成功状态和 Download 控件均被捕获。
- 观测剪辑顺序没有被改写为已证明的生成—导出流水线。
- `红发魔女Amber`、小红书与栏目标签没有被认作产品身份。
- 人物身份、来源、授权和生成归因保持未知。
- “实时、简单、低门槛、游戏角色/场景/电商模特”均保留作者主张标签。
- 负证据限定在 0–17.601 秒全片或 14.307–17.601 秒收尾，并同时承认内部 Download/Upgrade/Credits 等可见控件。
- SRT“高门键”与烧录字幕“高门槛”、以及异常原文“小白不上班”在结构化重建中均有保留。
