# Holdout2-3D Baseline 独立评测

## 结论

该 baseline **未通过硬 GATE**。它是一份可读性很强、范围意识也明显优于普通泛化总结的还原：主体是人头/脸部，游戏场景和电商模特只是作者扩张的用途主张；工具名、实时性、导出、拓扑、价格和商用条件也被大体保留为未知。

失败并不来自漏掉主线，而来自证据边界仍不够硬：baseline 多次把并排展示、笔触痕迹和快速剪辑写成“左侧操作后右侧随之生成”的已观察因果；同时没有持续守住左侧输入究竟是普通 2D 草图还是带体积的 3D 对象这一关键未知。结尾电影感人物与前述工具是否同源也没有明确保持为未知。

### Critical-question recall：8/12

正确回答或正确保持未知：Q01、Q03、Q05、Q06、Q07、Q08、Q09、Q12。

未完整回答：

- Q02：没有明确指出左侧输入可能是带深度/体积的 3D 对象，而非普通 2D 草图。
- Q04：没有把左右是否来自同一次实时会话明确列为未知，反而使用“随之呈现”“控制后变化”。
- Q10：写了价格、版权和商用未知，但未覆盖额度、隐私与训练数据政策。
- Q11：写了没有公开链接和领取规则，但没有守住工具包内容与安全性边界。

### Evidence coverage：6/7

K01、K03–K07 均有相应内容和大致时间定位。K02 未获得有效证据覆盖：视频能支持“作者把左右画面框定为输入/结果”，不能支持“画线/涂抹/拖动之后，右侧实时随之变化”的完整因果链。

### Unsupported inference：3/38

按去重后的实质性正面命题计数，排除明确引用、清楚标注的作者主张、未知项和重复改写。三项错误是：

1. 把左侧控制与右侧结果写成已观察到的因果关系。
2. 把结尾具体描述为“红色调的多个屏幕/人头画面”，允许证据只支持电影感人物面部蒙太奇。
3. 写成“女声中文口播”，而独立 audit/evidence-pack 没有提供可核验的说话者性别依据。

### Timestamp accuracy：4/5

00:00–00:15 的四个宽时间窗与审计时轴大体对齐。00:15–17.6 正确定位了人脸蒙太奇和 CTA，但加入了未被证据支持的“红色调多个屏幕”，因此该引用不计为正确。

### Process dependency completeness：N/A

独立审计将该素材判定为促销式演示，`tutorialCompleteness = none`。视频没有足够内容形成可重建的实际操作依赖链，因此本闸独立判为不适用，不能用 0/0 影响其他门槛。

### Unknown discipline：8/12

守住了工具身份、实时性能、输出/导出、后处理、场景/电商边界、版权/商用及异常字幕语义等主要未知。未充分守住四类机会：左侧输入类型；生成机制/模型/云端边界；额度、设备、账号与地区条件；评论区工具包内容与安全性。

### Unchecked channels：PASS

baseline 覆盖了口播/字幕、中央演示窗口、常驻包装、品牌水印和 CTA，没有整类可用载体被完全遗弃。这个 PASS 只表示“主要渠道看过”，不表示渠道之间的冲突与关系都被正确处理。

### Meta-gate：FAIL

- 未报告 SRT“高门键”和烧录字幕“高门槛”的跨载体差异。
- 左侧对象从“有明显三维体积的粗糙脸”被顺滑收束为“2D 草图”，意义变化未持续设防。
- 左侧操作 → 右侧结果、电影感人物 → 同一工具结果，两条关系都没有可靠证据闭包。
