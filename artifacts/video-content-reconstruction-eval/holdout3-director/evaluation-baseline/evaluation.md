# Holdout3 Director Baseline 独立评测

## 结论

**硬闸总体 FAIL。** 这份 baseline 是一篇可读性很高、主线召回很强的口播文章化重建：8 个关键问题全部回答，尤其准确抓住了“开头全面禁令 → 结尾允许 AI 辅助”的范围修正。但实际交付没有任何可核验的时间/cue/帧定位，未展示视觉与原始音频通道的检查结果，也没有系统保留未知和载体冲突。按统一协议，文笔不能抵销 GATE 失败。

## GATE

| 闸 | 计数 | 阈值 | 结果 | 核心理由 |
|---|---:|---:|---|---|
| Critical-question recall | 8/8 = 100% | ≥85% | PASS | 动机、可信度、选题、不能一键爆款、共情、60分、新旧账号、起号跃迁、AI 边界均被回答。 |
| Evidence coverage | 0/17 = 0% | ≥90% | FAIL | 语义约覆盖 15/17，但 17 个单元均没有单元级时间窗、cue、帧或其他有效证据定位。 |
| Unsupported inference | 5/40 = 12.5% | ≤5% | FAIL | 加入“注意力稀缺”“观众期待/账号信誉”“提高效率”等视频未给出的正向机制。 |
| Timestamp accuracy | 0/1 = 0% | ≥90% | FAIL | 候选提供 0 条可检查时间引用；用一个“至少提供一条可核验定位”的必检机会防止空集通过。 |
| Process dependency completeness | N/A (0/0) | ≥85% when applicable | N/A | 观点论证片，不展示可执行工序依赖。 |
| Unknown discipline | 2/8 = 25% | ≥90% | FAIL | 只正确限定了权重机制和坚持归因；模型范围、概念口径、平台范围、拼贴归属、字幕冲突和白板不可辨信息均未保留为未知。 |
| Unchecked channels | 2 条 | 必须为 0 | FAIL | 视觉载体与原始音频载体无可审计检查结果。 |
| Meta-gate | — | 零未守载体/关系 | FAIL | 整条视觉/音频通道和跨载体关系无人守护。 |

### 计数说明

- Evidence coverage 的分子要求“核心知识单元 + 有效证据”。只复述内容、不附定位，不计入分子；因此不能把约 15/17 的语义召回误报为证据覆盖。
- Unsupported inference 将重复表述合并；独立的新命题、新因果机制、新能力或新行动各计一项，共识别 40 个正向主张，其中 5 个没有视频内支持。
- Timestamp accuracy 不允许“零引用所以零错误”的空集真值。schema 要求分母至少为 1，本次把“是否提供至少一条可检查时间定位”计作一次检查，结果 0/1。
- Process dependency 独立判为不适用；不把 N/A 当 PASS，也不纳入其他闸的分子。

## 主要通过项

1. 正确避免把视频重建成“AI 完全无用”。结尾允许补知识、聊天和头脑风暴，同时反对一键生成完整脚本照拍，和开头口号形成的范围修正被准确表达。
2. 口播论证顺序基本完整：推广者动机 → 好选题 → 账号适配 → 流量不确定 → 人性/共情 → 60 分与权重 → 起号质量跃迁 → AI 辅助边界。
3. 对平台“权重”机制使用“作者的经验性解释”，对坚持与突然爆发使用“未必/也可能”，是少数正确的未知纪律。

## 决定性失败

### 证据与时间不可复核

`baseline.md` 没有一个时间窗、subtitle cue、frame 或 shot 引用。即便摘要语义大体正确，读者无法从交付直接回到视频验证“哪个时刻支持哪个单元”，所以 evidence coverage 与 timestamp accuracy 都失败。

### 整条视觉通道丢失

交付没有重建 0 秒数据拼贴、蜘蛛侠式面罩和白板授课场景、烧录字幕的黄色关键词、103–124 秒现场写“权重/100w/5w/3k/向下箭头”、128–143 秒缓升线与爆点、155 秒身份字幕以及结尾黑场。`baseline-process.md` 明确描述的是“按时间顺序完整通读字幕”，没有提供独立的视觉检查记录。

这不仅是少了美术描述，还漏掉了证据关系：开场拼贴只制造资历印象，数字归属和指标口径未知；白板数字与曲线只是同步说明，不是平台实证；结尾烧录字幕与 SRT 身份词还存在冲突。

### 文章化扩写超过视频边界

以下句子读起来合理，但视频没有给出对应材料：AI 输出会“标准、正确、顺滑却不具体”；平台注意力“极度稀缺”；普通内容会消耗“观众期待和账号信誉”；AI 能“梳理资料、指出遗漏”；AI “能提高效率”。这些应标为推断、删去，或提供外部依据，不能作为原视频的正向内容直接写入。
