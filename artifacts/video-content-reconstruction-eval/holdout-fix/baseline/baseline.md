# 用 HTML 解决 DeepSeek 内容复制到 Word 后排版错乱

## 视频讲了什么

把 DeepSeek 的回答直接复制到 Word，常会出现字体、字号、行距和段落结构被打乱的问题。视频给出的解决办法是：不要直接复制原回答，而是先让 DeepSeek 按指定排版生成 HTML，再运行这段 HTML，从渲染后的页面复制内容到 Word。这样标题层级和正文样式会随内容一起带入，能省掉大量手工排版。

## 操作步骤

1. 在 DeepSeek 中找到需要整理进 Word 的回答。
2. 继续发送提示词，要求它把当前内容用 HTML 格式重新输出，并把所需的字体、字号、行距、段后间距、对齐和缩进逐项写清楚。
3. 等 DeepSeek 生成 HTML 代码后，点击代码区的“运行 HTML”。
4. 新建一个空白 Word 文档。
5. 在运行后的排版预览中选中需要的文字并复制，再粘贴到 Word。
6. 检查结果。视频演示中，一级标题、二级标题和正文已经按要求呈现，不需要再逐段手工调整。

## 视频中的提示词示例

> 将内容用 HTML 格式输出，格式和排版要求如下：  
> 1. 一级标题：字体为三号仿宋 GB-2312 字体，行距 33 磅值。  
> 2. 二级标题：字体为黑体（三号），行距 30 磅值，段后空 0.5 行。  
> 3. 正文：三号仿宋 GB-2312 字体，对齐方式为两端对齐，首行缩进两个字符。

这个提示词只是示例。实际使用时，可把字体、字号和段落参数替换成单位、学校或个人文档规范；关键是让 DeepSeek 同时完成“HTML 输出”和“排版规则落实”。

## 可直接执行的要点

- 复制的是“运行 HTML”后的排版结果，不是黑色代码框里的 HTML 源码。
- 提示词越具体，粘贴到 Word 后越接近最终稿；至少应写清标题层级、字体、字号、行距和正文缩进。
- 粘贴后仍应快速检查字体是否在本机可用，以及 Word 是否保留了目标样式。

一句话总结：先让 DeepSeek 用 HTML 把内容和格式一起生成，再从渲染结果复制到 Word，就能明显减少排版返工。
