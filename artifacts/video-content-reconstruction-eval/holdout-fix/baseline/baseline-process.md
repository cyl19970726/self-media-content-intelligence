# 基线总结制作过程

本基线按普通的“完整总结视频，让读者知道关键知识、步骤与可执行事项”要求完成。

## 使用的材料

- 原视频：`6801c0750000000007037156.mp4`
- 同名字幕：`6801c0750000000007037156.srt`

## 整理过程

1. 通读字幕，确定视频要解决的问题：DeepSeek 回答直接复制到 Word 后格式混乱。
2. 按时间顺序查看视频画面，核对实际操作链路：提出 HTML 排版要求、生成代码、点击“运行 HTML”、新建 Word 文档、从渲染结果复制并粘贴。
3. 从画面中抄录示例提示词里的三级排版要求，包括字体、字号、行距、段后间距、两端对齐和首行缩进。
4. 将内容整理为“问题—方法—步骤—示例提示词—执行提醒”的普通总结结构。
5. 对字幕中容易产生歧义的表达以画面为准：最终应复制的是运行 HTML 后的可视化排版内容，而非 HTML 源代码。

## 取舍说明

- 保留了完成任务所需的完整操作步骤和可复用提示词。
- 示例回答本身讨论的具体主题与技巧无关，因此未展开总结，只作为待排版内容处理。
- 对视频未演示的高级设置、兼容性方案和额外工具不作扩展；仅补充了粘贴后检查字体与格式这一项常规执行提醒。
