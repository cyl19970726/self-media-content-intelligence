# Holdout-fix baseline 独立评审

## 结论

Baseline **未通过硬 GATE**。它是一份清楚、可直接照做的普通总结，核心桥梁“先运行 HTML，再复制白底渲染结果”也抓对了；但在同一套独立审计口径下，只有流程依赖完整性通过。关键问题召回、证据覆盖、不支持推断、时间戳准确、未知纪律和载体扫查均未过阈值。JUDGE 分数仅描述阅读与执行质量，不能覆盖 GATE 失败。

## 最重要的保留与失败

最值得保留的是 baseline 明确说“复制运行 HTML 后的排版结果，不是黑色代码框里的 HTML 源码”，这准确覆盖了 Q-04、SEM-01 和 REL-02，也是视频最容易被纯字幕总结漏掉的视觉桥梁。

最重要的失败是把画面中的 WPS Writer 写成 Word，并进一步让读者以为 Microsoft Word 已被视频验证。审计只支持“口播泛称 Word，画面实测 WPS Writer 的 `.docx`”；兼容 Microsoft Word 仍是未知。第二个硬伤是无证据定位，因此即便大部分操作信息正确，也无法满足“带有效证据”的覆盖要求。

详细逐项差异见 `discrepancies.md`；机器可读结果见 `evaluation.json`。
