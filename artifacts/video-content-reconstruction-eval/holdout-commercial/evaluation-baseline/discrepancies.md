# Baseline 差异与缺口账本

## 计数口径

- 关键问题以独立审计的 Q-001–Q-008 为母集。
- 证据覆盖使用 20 个可独立证伪的核心单元：13 个时间载体，加上全片声明、第一方演示边界、视觉语言、非旁白音频、转化缺席、隐私/数据条件、提醒语义张力等跨段单元；只有“事实与证据边界同时保留”才计 1。
- 无支持推断按 baseline 中去重后的原子肯定命题计数，共 51 条；问题、标题、明确未知和纯重复不计。
- 未知纪律以审计 UNK-001–UNK-009 为母集；只“不作断言”但也未识别该未知，不计为正确处理，避免用沉默自证完整。

## 缺失或边界不完整的核心证据单元（8/20）

### 1. 敏感健康资料是服务前提

画面在品牌揭示后展示成员关系、昵称、性别、出生年份，以及过敏史、家族史、疾病史、孕产史、烟酒史等字段。baseline 只写“结合个人情况”，没有重建实际数据门槛。结果是它虽质疑隐私承诺，却没有呈现隐私风险为何在本片中尤其重要。

### 2. 咖啡建议的证据层级

baseline 写“再给出‘不要继续加量’之类的参考建议”。允许证据清楚显示的是杯数/时间追问；最终“不加量”主要来自主播口播，画面未清楚展示完整结论。应区分“主播声称”与“界面可见”。

### 3. “不催”与每日提醒的张力

baseline 保留“不不断催促”，但睡眠任务页明确写“我将每天提醒你打卡”。正确边界是：可能强调提醒语气温和，不等于没有提醒。

### 4. 声明与来源标签

漏掉两个高价值屏幕文字载体：开头“资料画面非本新闻事件”，以及全片底部“本内容为产品体验分享，身体不适请及时就医”。前者限制新闻画面的证明力，后者同时承担商业披露和医疗安全边界。

### 5. 视觉修辞和产品状态序列

主播左下画中画、红发动画女性替身、顶部金色关键词、产品 UI 状态推进，以及 89.4–93.7 秒同一长页快速滚动均未重建。普通总结虽能覆盖口播，却不能让读者知道视觉如何把恐惧、同类认同、功能详尽感与信任承诺组织起来。

### 6. 非旁白音频

约 8.5 秒后存在持续的背景音频/配乐床。baseline 完全未检查非旁白音频，也未把曲名、曲风、作者与授权标为未知。

### 7. CTA 的转化强度

baseline 写到片尾互动问题，但未记录画面没有二维码、下载路径、价格、优惠或限时条件。因此没有把它判为评论/自我代入式软 CTA，而非硬销售转化。

### 8. 第一方演示的可复现性

baseline 质疑专业与隐私宣传，却没有明确指出 UI 可能是预录、剪辑、预设或特定版本。功能示例支持“片中出现了这些状态”，不支持一般可用性、长期表现或版本可复现性。

## 无支持推断（6/51）

| Baseline 命题 | 问题 | 应守边界 |
|---|---|---|
| “连续补充背景……能让建议更贴近个人实际情况” | 从单次第一方演示推广到一般性能 | 写成视频的价值主张；相关性与安全性是否提高仍未知。 |
| “单看一个症状很难得到有针对性的回答” | 新增一般医学/信息判断结论 | 最多写“视频借此主张需要更多上下文”。 |
| 疲惫/注意力不集中时“先记录……再咨询或调整” | 把广告场景改写为观众健康行动建议 | 不应给出自我调整规则；持续或警示症状应就医。 |
| 身材管理时据此“决定是否需要增加力量训练或优化饮食” | 把产品示例改写为可验证的决策方法 | 只能说片中产品示例这样建议，不能证明适合观众。 |
| “从一个足够小的习惯开始” | 视频举小目标例子，但没有验证该原则 | 若保留，需标为总结者建议而非视频知识。 |
| “而不是一次设定过多目标” | 允许证据未出现 | 删除或外部补证；本评测禁止给 baseline 补证。 |

## 未知纪律（4/9）

### 正确保留

- UNK-001：新闻来源/病因/事实准确性与因果未核验。
- UNK-004：“高专业标准”的依据、专家审核与准确率未知。
- UNK-005：“完全确保隐私”的政策与机制未知。
- UNK-009：没有独立效果数据，不能推出实际改善。

### 未识别

- UNK-002：UI 是真实在线操作、预录、剪辑还是预设，及版本可复现性。
- UNK-003：32 岁、168cm、55kg 等是否为主播真实资料。
- UNK-006：平台、访问方式、费用、地区限制、账户与责任主体。
- UNK-007：主播是否获报酬、是否广告投放、体验是否独立。
- UNK-008：背景音频的身份、作者、授权和独立转场音效。

## 元闸缺口

### 未守载体

- 非旁白音频床。
- 开头资料画面来源标签与全片持续声明。
- 敏感健康资料表单、问询进度、具体计划任务、每日提醒。
- 主播/动画替身/产品 UI 的视觉关系与状态顺序。
- 无二维码、访问路径、价格、优惠和限时条件的缺席证据。

### 未守意义变化

- “连续追问”从输入收集被升级成“理解你、建议更贴近你”，但一般性能未验证。
- “不会催”没有被“每天提醒”限定。
- 免责声明既是医疗边界，也被商业叙事借作“专业、克制”的印象证据；免责声明本身不能验证专业性。

### 未守关系

- 隐私强承诺 ↔ 身份、健康史、身体数据与习惯收集。
- 第一方 UI 演示 ↔ 独立效果、一般可靠性与版本可复现性。
- 每日提醒 ↔ “不会催”的体验性口播。
- 片尾提问 ↔ 缺少硬转化路径。

## 保留的优点

- 没有把脑梗个案与熬夜/油腻饮食的连续呈现写成已证实医学因果。
- 没有把阿福写成医生或诊断替代品，且给出严重/突然症状及时就医的安全边界。
- 对“高专业标准”“绝不制造恐慌”“完全确保隐私”的归因和证据不足说明准确。
- 口播的商业说服顺序压缩清楚，可读性强。
