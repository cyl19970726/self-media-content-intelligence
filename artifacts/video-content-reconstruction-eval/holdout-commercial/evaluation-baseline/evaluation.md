# Holdout-commercial 普通总结 baseline 独立评测

## 结论

**硬门禁总判定：FAIL。** 关键问题召回和已给出的时间引用准确性通过；证据覆盖、无支持推断、未知纪律、未检查载体和元闸失败。过程依赖门禁不适用。JUDGE 分数仅描述可读性与使用质量，不能覆盖硬门禁失败。

这份 baseline 的优势很明确：它准确抓住了口播主线，能把脑梗个案与产品功效拆开，也把“高专业标准”“绝不制造恐慌”“完全确保隐私”保留为作者/产品的未验证宣传主张。主要失败不在文笔，而在证据拓扑：生成过程以字幕为主，没有完成视觉、屏幕文字和非旁白音频 sweep，因而漏掉了决定商业与医疗边界的关键载体和跨载体张力。

## 最关键的边界判定

1. **病例与脑梗因果：处理正确。** baseline 明确指出熬夜、油腻饮食与脑梗只是连续呈现，视频没有给出具体因果证据。
2. **专业与隐私主张：归因正确但条件不完整。** 它正确标为宣传主张，却没有写出产品要求提交身份、出生年份、健康史、身体数据与习惯，这正是隐私承诺必须被严格审查的条件。
3. **第一方演示：过度外推。** 画面只能证明剪辑后的示例里出现追问、计划和提醒；baseline 的“补充背景能让建议更贴近个人实际”把示例升级为一般性能结论。
4. **“不会催”与每日提醒：语义张力漏失。** UI 明写“每天提醒你打卡”，因此只能解释为提醒语气温和，不能总结成不会不断催促。
5. **医学执行建议：超出视频证据。** “先记录再调整”“据此决定力量训练/饮食”“一次只设一个小目标”等是总结者新增建议，不能由这条商业视频直接推出。
