1. 三种分析是否应分别成为单帖、专题和博主项目。
2. 三页首屏是否回答了正确问题。
3. 右侧证据检查器是否符合“结论必须可追溯”的工作方式。
4. V3 是否应以 ResearchProject 为核心，并把 Run 降为执行记录。
5. 内容模型、Brief、发布复盘和 Notion 同步的边界是否合理。

确认后从 `tasks.md` 的 Phase 1 开始实现，并持续回填任务状态。
