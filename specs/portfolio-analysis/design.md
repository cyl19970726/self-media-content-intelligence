# 系列与博主分析 — 设计

## 入口

- 首页新增模式：单帖 / 系列。
- 单帖报告在作者信息附近增加“分析该博主”。
- 路由新增 `/portfolios/:id`，任务异步采集并可重试。

## 数据契约

`PortfolioReport` 包含：

- `scope`: creator 或 series；
- `creator`: 用户资料和公开统计；
- `posts`: 标准化帖子快照；
- `portfolioMetrics`: 中位数、离散度、Top 20% 贡献、命中率；
- `pillars`: 由标题/标签得到的内容支柱，附帖子数和相对表现；
- `repeatablePatterns`: 至少在 3 条帖子重复出现且表现稳定的模式；
- `outliers`: 高于或低于组合基线的帖子；
- `evidenceCoverage` 与 `limitations`。

## 判定原则

- 先逐帖归一化，再做组合统计。
- 爆款依赖度 = Top 20% 帖子的已知互动 / 全部已知互动。
- 稳定性使用帖子互动相对中位数的离散程度，不用平均值掩盖极端值。
- 内容支柱只在至少 2 条帖子中出现时展示。
- 缺少浏览、关注转化和后台受众时，相应结论保持未知。

## 采集边界

小红书必须通过仓库内 `xiaohongshu-skills/scripts/cli.py` 获取详情和主页。适配层记录扩展未连接、未登录、风控和样本不足状态。
