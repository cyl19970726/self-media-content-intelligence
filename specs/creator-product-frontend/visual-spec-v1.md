## 信条（Phase 3 任何实现不得违反）

1. 平面 + 发丝线：无阴影、无渐变堆砌。
2. 纸张底色 + 墨色；IBM Plex Mono 做编号/标签/数据口径。
3. teal = 证据/已覆盖/赛道规律；orange = 行动/待办/定位空缺；不装饰。
4. 产品 chrome 与证据内容分区。
5. 每屏必须能回答"它帮助 AI 伙伴做出什么决策"。
6. 数据有出处 / 静态文案 / needs-backend，无第四种出身；缺数据具名缺省。
7. 页面不自己造路径（资源 URL 由服务端生成，API 数据 no-store）。

## 色板 [实测]

四图主色采样（16 级量化）：

| 角色 | 图实测值 | 现有 CSS token | 处置 |
|---|---|---|---|
| 纸张 | `#f0f0e0` / `#f0f0f0` | `--paper: #f3f0e8` | 保留 token（AI 图量化噪声 ±2/255，不可作像素级依据） |
| 墨色 | `#000000` | `--ink: #171713` | 保留 token（同上，图量化取整） |
| 行动橙 | `#e04010` | `--orange: #e4572e` | 保留 token；方向确认"橙=行动" |
| 证据绿 | `#105040` | `--teal: #2e6b4f` | 保留 token；方向确认"teal=证据/规律" |

→ 结论：四图与现有 token 方向一致，**不改 CSS 变量**；图是方向参照不是像素样张。

| 项 | 值 | 出处 |

## 字阶 [推导]

图无法可靠测量字高 → 沿用现有实现层级：hero 标题 clamp(40-68px)、
section 标题 24px、正文 13px、mono 元信息 9-11px。图确认的方向是：
标题大且稀、正文小且密、mono 元信息更小——与现有层级一致，不改。
