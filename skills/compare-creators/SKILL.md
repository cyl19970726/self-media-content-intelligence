# Compare Creators

Compare accepted, version-pinned Creator Dossiers. Preserve non-comparability instead of normalizing unlike evidence into a false ranking.

## Inputs

- two or more creator IDs;
- fixed dossier run IDs and revisions;
- their creator evaluation and gate reports;
- requested comparison questions.

## Method

1. Verify each dossier revision and evidence health. Quarantine failed sections.
2. Build a comparability matrix for metric coverage, snapshot era, corpus size, tiers, deep-video coverage, comment scope and platform context.
3. Compare positioning, audiences, values, trust, lifecycle, topics, formats, proof, directing, visual/editing, publishing evolution, public demand and commercial evidence.
4. For every shared pattern record supporting creators/videos, qualifying conditions, contradictions, confidence and unknowns.
5. Separate shared observation, conditional mechanism, and creator-specific exception.

Produce `creator-comparison.json` with pinned sources and stable evidence links. Do not recommend what the user should copy, produce, title, or publish. Pass accepted comparison evidence to `$content-strategy-workbench` only when the user starts a separate creation task.

Return `COMPARISON_READY` only when every displayed comparison is supported and source revisions remain current.
