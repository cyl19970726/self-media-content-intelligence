# 报告工作台与执行进度

单帖阅读页是主要入口：上方呈现当前工作流进度、报告版本与审阅状态，下方继续使用完整的内容还原、编导结构、画面与剪辑和就近证据。执行详情用于排障，不承担主报告阅读。

## 数据边界

- 运行时负责持久阶段、资产版本和依赖关系；业务阅读投影将这些事实组合为当前报告及进度。不根据页面耗时或缺失用量推断模型是否调用。
- 按研究批次与帖子绑定工作流。明确指定某次工作流时不能悄悄回退到另一篇帖子或另一批次；子流程入口解析到所属单帖研究流程。
- 当前候选从已登记的有效资产读取，正文沿用 artifact reader 的 Builder 投影；页面不得用摘要或旧报告补写新候选。
- 修订稿未再次独立审阅时，必须明确标识；执行成功、结构校验成功和独立审阅通过是不同事实。
- 修订前报告通过修订记录中绑定的 baseCandidate 快照读取。普通批次入口可能已登记新版本，不能将该入口误称为历史原稿。工作流失败但已有候选时，候选仍可读，并显示流程失败。

## 阅读与操作

从博主作品库打开单帖即可查看关联工作流与当前可读候选。报告页保留章节和证据，修改说明默认折叠。新发起研究后留在同一报告页，进度随运行更新；执行详情链接保留批次范围，详情页可返回绑定本次流程的报告工作台。

这轮使用既有拉链报告及修订资产验收，不重新调用模型、不自动晋升候选，也不改变 Builder 原文。原博主综合仍是对应批次的原成果，本次实现范围为单帖报告工作台。
