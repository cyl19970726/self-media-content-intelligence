# 单帖与单博主工作台：目标和执行原则

当前工作台的阶段目标是建立可追溯的理解：先看清一条内容究竟说了什么、展示了什么和没有交代什么；再理解编导组织与画面作用；最后在同一博主的不同表现样本之间，辨认重复结构、差异、反例和研究边界。

## 推进顺序

1. 单帖：真实阅读代表样本 → 定位问题 → 修复 → 独立 real user Agent 复验。
2. 单博主：单帖验收通过后，研究基本盘、高中低与中位/均值选样、综合到单帖的证据路径 → 修复 → 独立复验。
3. 多博主、知识或创作功能需要另立小闭环，不因现有入口而自动扩展本轮范围。

## 实施原则

- 先实际使用，再决定改什么；字段数、门禁数字和测试通过率不能替代读者理解。
- 分清源内容未知、分析未产出和页面遗漏。保留未知，修复遗漏；不为填满页面猜补。
- Builder 三 Lens 保持唯一事实源。历史原文明确版本、连续可读，不冒充新格式；下游综合明确身份，不静默替代源结论。
- 兼容层只负责字段、状态、引用和媒体投影。优先增量修改已有路径，避免通用页面引擎和大规模架构重写。
- 公开基本盘、选样集、深读集各自有分母；表现分层与选样角色各自有含义。归纳判断保留支持、反例和混杂因素。
- 状态注明所对应的任务、报告和评估版本；原任务通过不能代替当前规则复核。跨页面保持同一批次。
- 由独立读者完成复述、解释、证据定位和往返阅读任务。用保留样本及不同内容形式复验，不把叙事作品按教程缺步骤判失败。
- 每轮提交可用改动、测试及真实使用记录，同时留下未解决的研究边界。本轮使用隔离数据快照、原库和原证据只读，未重跑模型。
