# 博主研究列表调整

## 交付范围

- `/creators` 默认进入研究工作台，每位博主一行，直接显示当前阶段、单帖执行数量、更新时间和操作。
- `/creators?view=completed` 显示已完成研究。
- 添加博主保留原有 RedFox 批量入口，通过折叠入口打开。
- 移除首页重复的权威状态区和博主卡片，不改写单帖或博主研究正文。

## 分类规则

研究产出必须同时满足运行状态 `ready` 或 `reviewable`、存在 `synthesisArtifactRef`、博主综合和交付阶段均为 `complete`。`reviewable` 明确显示“研究已产出 · 待验证”；单帖全部构建完成本身不代表综合研究已产出。

研究工作台按每位博主最新创建的运行显示一行。已完成研究保留其最新的完成运行，因此再次研究时仍可查看原有完成结果。旧的未完成尝试不会因为更新时间较新而覆盖新运行。
