# 单帖报告阅读升级

## 阅读结构与原文边界

页面采用整篇总览、内容还原、开头与包装、编导结构、画面与剪辑。研究审计保留次级入口。四个阅读入口复用原三个 Builder Lens，不新增第四份分析事实源。开头与包装集中展示既有 openingAnalysis 和 packagingAnalysis；旧的 #visual-opening、#directing-packaging 深链接仍定位到对应内容。

编导、镜头、UI 状态、转场、节奏、连续性缺口使用统一的段落与字段布局，引用就在结论下方。转场不再截取前两条引用；SHOT 引用解析为实际镜头代表帧，明确说明不是切点画面。正文图片可打开原图；内容块保持完整、连续、原始顺序。时间范围检查只提示倒序和超过0.5秒的未覆盖范围，不推断遗漏内容，不重排或补写结论。

## 综合总览与兼容

新增 report-overview.json 是明确的下游综合分析，独立于 reconstruction.json。API 同步加载、校验原报告 SHA256、版本与每段 JSON Pointer。展示层仅排版原文，并将依据链接到具体内容块或对应分析章节。状态为 missing、stale、invalid 时显示可理解的提示；生成失败或未知也不冒充成功。

既有 VideoResearch schema 在集中合同中为 overview 提供 missing 默认值，旧报告无需重写。没有 openingAnalysis 或 packagingAnalysis 时明确显示未产出。新增分析沿用稳定业务组件，不引入通用页面引擎。

生成入口（默认显式 Terra + medium，独立于先前 Astra 迁移）：

```sh
npx tsx scripts/generate-report-overview.ts --reconstruction /absolute/path/reconstruction.json
```

仅读取已有 Builder 数据，不重复视频采集或分析。可配置 SELF_MEDIA_REPORT_OVERVIEW_MODEL 和 SELF_MEDIA_REPORT_OVERVIEW_REASONING_EFFORT。生成前后确认原报告字节未改变；发布前校验引用与格式。当前为显式 CLI 步骤，未默认加入批量分析或自动额外消耗模型额度。

## 真实检查与信息缺口

开发使用实际单帖报告，并由独立模拟用户代理通过真实浏览器执行桌面和390px检查。该代理不是人类用户。截图与详细复现仅留忽略的 .runtime/report-refresh-qa/，不提交原帖媒体或私人运行日志。

已发现并修复：内容图不能打开、正文大竖图拖长阅读、UI/连续性缺口缺少附近引用、转场只展示部分引用、SHOT来源未解析、阶段英文标签阅读成本（保留原名）、镜头代表帧时间标签歧义。原始结论和证据未知项不由前端修补。

原样本仍有内容块倒序和时间范围未覆盖；需要 Builder 对照原视频在新修订中补充。界面参数/文件内容不可读、完整短剧未展示、音乐音效语义未知属于证据缺口。增加字段不能解决这些问题；应针对性采集或维持未知。镜头代表帧不是精确转场前后帧，需要精确分析切点时还应补取对应画面。

## 回归

服务端覆盖总览缺失/损坏/过期/引用无效及生成中原报告变化；前端覆盖原文保留、证据完整可达、旧报告总览缺失、过期总览不展示、来源导航和时间范围检查。外部历史证据库只读接入用于历史报告验收。运行记录与最终检查数字以当次交付为准。

## 本轮交付验收（2026-09-10）

389 项测试通过、1 项条件性跳过；lint、构建、文档链接及仓库边界检查通过。实际样本139个媒体/资源链接全部返回成功。原有内容块、主张、未知项、编导及画面剪辑字段与升级前一致；总览源哈希匹配。

模拟用户代理实际验证四入口、连续正文、原图打开、390px阅读及历史报告；修复移动锚点遮挡、重复同一依据链接不能重新定位和亚秒转场范围舍入问题。主代理在内建浏览器补验“研究审计 → 旧版原始报告”，完整旧版原文可展开。历史报告仍有17处来源未解析，明确保留缺口。

## 认知价值复盘与下一轮方向

本轮完成阅读、最小数据补充与兼容验收，不等于报告已达到创作指导质量。当前样本仍为 BUILT_UNEVALUATED，不能称为独立评估通过。

用户重新提出项目目的问题。建议后续以“帮助创作者理解真实案例的内容组织与表达，并形成有证据、有适用条件的创作判断”为产品方向；此处是待进一步验证的建议，不替换既有 Builder 事实合同。三个 Lens 是分析视角，四个入口是阅读组织，均不是用户最终收益。

下一轮认知验收应让未看原视频的读者完成三项任务：准确复述主张、过程、证据和未知；解释关键创作选择如何组织理解（区分观察与推测）；提出带适用条件和限制的借鉴方案。当前内容还原已有基础，前后编导关系仍需加强，剪辑分析部分偏现象描述，迁移到自己创作的支持最弱。不得从互动量直接推断剪辑效果因果，也不得由前端补写这些结论。

剩余轻微体验项包括总览同名依据链接可进一步细化，以及源文术语的中文解释；这些不妨碍原始字段访问。针对内容覆盖、操作参数、声音语义与精确切点的缺口，应在新的源分析修订中补证据；需要迁移建议时作为明确的下游分析。
