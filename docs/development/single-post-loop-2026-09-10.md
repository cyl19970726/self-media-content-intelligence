# 单帖小闭环：真实阅读基线与修复

目标与范围：先让单帖支持理解内容、理解组织与画面作用、回到证据及保留未知，再验收单博主。此轮不扩展多博主、知识或创作功能；原始库与证据只读，不重跑分析来掩盖投影问题。

## 独立使用基线

独立 real_user Agent 通过实际页面阅读秋芝 Codex（高）、本地 RAG（基本盘）、木兰（低叙事）、张咋啦两遍录制法及一份新三 Lens 报告。使用隔离主库快照，浏览器 Space 32；原始操作记录位于本地 `.runtime/single-post-loop/`，不纳入仓库。

- 秋芝三帖的四个主要入口基本为空；有价值的正文在研究审计的三级展开中。Agent 从原文能复述 Codex 文件/网站/技能/自动化及失败实例，RAG 的模型/嵌入/向量/工作区关系与网页、清理文档两次回答对照，木兰的代征动机、双重危险、誓词与战斗蒙太奇。这是投影遗漏，不是没有分析。
- 原任务标 ready、Evaluator 原文写通过，页面却写 failed。实际文件为 `runtime-three-lens-evaluation@1`，当前校验只接受 `@2`。这是兼容校验不可用，不能冒充旧评估失败，也不能直接晋升为当前规则通过。
- 张咋啦的误读风险被放在分析说明中，脱离字段语义后像推荐结论。原文图片使用旧本机绝对路径，不能就近点开。
- 新三 Lens 报告的正常路径能让 Agent 复述内容与编导作用，并打开证据。已提示的时间覆盖缺口仍待回看；静态操作状态标签、相同依据链接名和未评估状态的措辞有歧义。

## 实现边界

- 增量接口字段只有报告格式、已解析原图映射、评估读取诊断与独立风险列表；默认值兼容旧调用者。
- 历史原文在内容入口连续显示，目录只定位。没有转换成 builderLenses，没有删逐字稿、改标题、写摘要或隐藏限定。新 Builder 主报告仍由 builderLenses 驱动。
- 原文附近解析已有 TARGET/CUE/HIRES 等引用；明确登记的高清帧清单纳入索引。旧图片路径只投影到已经存在且由证据服务提供的文件；不请求任意远程图片，不公开其他本地文件。
- 历史格式、当前评估不可用与旧任务记录分别表达。详细校验诊断和原始评估文件可追溯；不修改门禁状态或原始文件。
- 误读风险从 notes 分离并按原含义标注；新报告状态角色注明“报告标注”，证据采集记录不冒充画面解释，总览依据链接直说目的地。

## 不能用界面补齐的内容

报告中实际未展示的运行参数、费用/隐私/效果核验、工作区切换连续性、木兰战役结局与具体制作模型，继续是源信息边界。新报告的 10–21、40–45、53–59 秒标注空隙，以及 38 秒首次成果与后段样片的组织关系，需要回到源视频研究；不能仅凭时间空隙断言分析漏掉内容。
