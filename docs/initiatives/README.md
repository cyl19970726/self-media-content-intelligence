# Initiative Records

This directory owns scoped plans and acceptance evidence. It does not own
permanent product or architecture truth.

- `active/` contains work with unresolved acceptance items or continuing research.
- `completed/` contains frozen implementation records whose still-valid facts
  have been promoted to `docs/product`, `docs/architecture`, ADRs, or code.

Moving a record to `completed/` never means every idea in its original design was
implemented. It means the bounded task list was accepted and the record is now
historical. Use the [initiative inventory](../initiative-inventory.md) for the
authoritative maturity and verification classification.
