## 关键修复

1. 单博主概念身份改为综合报告的 `recurringStructure`，并通过 evidence ref 绑定具体帖子。
2. compiler policy 和 analysis revision 同时版本化，防止不同语义复用同一分析版本。
3. 所有新单帖、单博主和比较研究先进入 proposal store。
4. 审核必须携带冻结输入指纹；旧页面不能应用新版本。
5. 非晋升结果同样持久化为保留、等待或拒绝。
6. fixture 在历史激活计划中直接拒绝，禁止进入生产 Knowledge。
