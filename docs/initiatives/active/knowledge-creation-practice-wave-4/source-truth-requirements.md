# 原帖事实层需求

## 问题

系统已经能重建视频并形成博主规律，但标题、发布正文和封面没有作为独立事实合同贯穿页面。操作者容易把平台原文、视频逐字稿、OCR 和模型重建混在一起。

## 两级范围

1. 全量作品保留标题、主页卡片文字、媒体类型、公开点赞、缩略封面候选和来源。
2. 进入 21 条比较集的作品补齐详情标题、发布正文、发布时间、本地封面/图集和采集证据。
3. Builder 与 Evaluator 只消费事实快照，不反向修改事实。

## 验收条件

- 当单帖报告存在来源数据时，系统必须在分析结论之前展示标题、发布正文、封面、话题、发布时间、指标、来源和采集时间。
- 当发布正文只有话题标签时，系统必须标记为“部分取得”，不得称为完整正文。
- 当封面或正文缺失时，系统必须显示缺失状态，不得用关键帧、逐字稿或模型摘要冒充。
- 当博主比较集包含作品时，每个作品必须携带同一份原帖事实投影；深度证据页必须展示该投影。
- 发布正文、视频逐字稿和画面 OCR 必须使用不同标签和页面区域。
- 历史 artifact 缺少新字段时，读取必须向后兼容并投影为未知。

## 非目标

- 不为所有作品下载完整视频或图集。
- 不重跑现有 20 个博主。
- 不把封面视觉因果分析塞进事实层。
