# Wave 4：第一条 Knowledge → 创作 → 实践闭环

对应 Issue：[#46](https://github.com/cyl19970726/self-media-content-intelligence/issues/46)

## 我们要证明什么

研究不能停在“看起来有道理”。它必须进入一次真实创作，并在发布后接受真实结果检验。

Wave 4 要让操作者回答五个问题：

1. 这条内容用了哪一版知识？
2. 哪些结论被采用、改编、拒绝或拿来测试？
3. 发布前到底预期什么结果，和什么基线比较？
4. 实际发布的是哪个冻结版本？
5. 结果支持、限定还是反驳原知识？谁做了独立裁决？

## 验收条件

- 建立 3 个使用真实素材和已审核 Knowledge 的内容包。
- 每个内容包固定 Knowledge revision，记录使用方式、理由和可证伪假设。
- 每个内容包至少有 1 个冻结平台版本。
- 产品能从发布任务追溯到冻结版本、假设、Knowledge revision、研究观察和 Evidence 引用。
- 选择 1 个内容包进入真实平台预览；最终发布必须由用户单独确认。
- 发布后记录可用指标、不可用指标、执行偏差和混杂因素。
- 实践判断与独立裁决分开；裁决只追加历史，不重写旧 Knowledge。

## 不做什么

- 不因点赞高就自动把假设升级成规律。
- 不把取不到的曝光、完播或转化写成 0。
- 不绕过用户确认点击平台最终发布按钮。
- 不为了 Wave 4 重写已有发布架构。
