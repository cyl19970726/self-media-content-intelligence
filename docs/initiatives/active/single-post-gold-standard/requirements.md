# 单帖金标准 · 需求

## 目标

先让一条帖子成为可追溯、可阅读、可复用的知识资产，再允许它进入单博主分析；单博主稳定后，才进入多博主比较。

## 验收要求

- 当 Builder 处理视频时，Host 必须生成普通 cue 到最具体知识单元的候选回链，Builder 只判断语义例外。
- 当知识单元覆盖不连续片段时，Builder 必须拆分单元，不得扩大一个连续时间范围包住片头与结尾。
- 当帖子标记为 `VERIFIED` 时，所有 `knowledge/context` cue 必须有有效知识单元回链。
- 当正文使用图片时，图片必须紧邻它证明的内容，并说明可见事实与证据边界。
- 当正文展示操作序列时，同一批图片不得先作为图库重复一次，再作为步骤重复一次。
- 当正文展示前后变化时，必须按前、过程、后的阅读顺序排列。
- 当 Evaluator 发现问题时，系统只报告，不自动改写冻结候选。
- 当单帖没有通过证据、内容、页面和人工阅读四类验收时，单博主综合分析不得把它当作正式知识。

## 非目标

- 本阶段不启动整位博主的全量重跑。
- 本阶段不启动多博主比较。
- 不以一次 Gate 全绿代替人工阅读质量验收。
