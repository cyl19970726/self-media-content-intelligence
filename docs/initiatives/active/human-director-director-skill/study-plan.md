# 人类最强编导：全量内容重建与深度编导 Skill 学习计划

状态：已完成。`video-content-reconstruction` 已返回 `READY_FOR_DOWNSTREAM_USE`；19/19 视频完成重建，14 条归纳样本完成 observation，5 条冻结保留集完成独立盲测，`deep-content-director` 已通过静态发布审查与三项真实前向测试。

## 1. 最终目标

不是复制博主的强人设、毒舌语气或收入背书，而是从全部公开视频中提炼一套可迁移、可执行、可反证、能接受发布结果修正的编导工作方法。

最终交付：

1. 19/19 视频内容重建库；
2. 重点、辅助、保留测试三层样本；
3. 编导知识图谱和冲突/边界表；
4. 可调用的深度编导 Skill；
5. 用未参与归纳的视频和我们自己的真实选题做盲测；
6. 起号、单条制作、系列规划、发布和复盘模板。

## 2. 前置硬闸

只有上游 Skill 同时满足以下条件才开始全量重建：

- canonical Skill 路径存在并通过 `quick_validate.py`；
- 有真实开发集和未参与调参的保留集；
- 核心知识单元带时间码与字幕/画面证据；
- 能区分原始事实、作者主张、系统推断与未知；
- 有 coverage matrix 和未检查通道 meta-gate；
- 评测不是只判断文章是否流畅；
- 上游 final 明确输出 `READY_FOR_DOWNSTREAM_USE`。

任一失败则退回上游修复，不使用部分完成版本。

## 3. 全量重建协议

对 19 条视频逐条执行：

1. 第一轮探针：观众变化、信息载体、意义变化、关系结构、遗漏风险；
2. 生成该视频专属《内容捕捉协议》；
3. 第二轮还原：逐字稿、知识单元、关键帧、操作/状态、主张/证据、条件、反例、未知；
4. 第三轮完整性审计：字幕簇、视觉变化、OCR、评论/案例、未检查通道；
5. 输出统一 evidence pack 和 reconstruction JSON；
6. 不读取已有人工 `summary/why` 作为答案，只在重建完成后用于差异审计。

## 4. Observation 学习循环

每条视频不直接归类成“一个方法”，而走六步：

### O1 — Observe

只记录视频实际说了什么、展示了什么、如何推进认知，不评价对错。

### O2 — Model

把内容建成关系图：

`人群 → 需求 → 定位 → 人设 → 选题 → 脚本 → 画面 → 证明 → 发布 → 数据 → 复盘`

不存在的节点保持空，不用常识补齐。

### O3 — Ask back

对每个方法反问：

- 它解决谁的什么问题？
- 视频给了什么证据，还是只有作者权威背书？
- 成立需要什么账号阶段、资源、身份和平台环境？
- 哪个反例会推翻它？
- 它与同账号其他视频是否冲突？
- 怎样把它变成一个具体制作动作？
- 发布后用什么指标才能判断有效？

### O4 — Contrast

把同一主题的多条视频并排，区分：

- 重复出现的稳定原则；
- 只出现一次的观点；
- 随账号阶段变化的策略；
- 为塑造人设服务的表达；
- 可执行方法与情绪/价值观内容；
- 公开表现与真实因果之间的缺口。

### O5 — Apply

用原则生成我们自己的选题、脚本、镜头和发布实验，禁止改写原博主案例冒充迁移。

### O6 — Review

把真实发布结果回写：确认、修正或否定原则。Skill 只保存经过验证的稳定方法，未验证内容保持 hypothesis。

## 6. 深度编导 Skill 的能力闭包

最终 Skill 至少覆盖：

1. 研究问题与目标人群；
2. 账号定位和身份承诺；
3. 选题来源、需求强度和内容支柱；
4. 单条承诺、标题/封面、前 3 秒；
5. 脚本论证、故事、教程和证明链；
6. 画面功能、镜头变化、信息载体和认知负荷；
7. 节奏、删减、keep/compress/remove 与 cut list；
8. CTA、系列延续、搜索和评论承接；
9. 发布假设、指标、守护指标和观察窗口；
10. 复盘、反例、结论修订和内容模型沉淀；
11. 平台适配与不可跨平台照搬项；
12. 合规、版权、健康/商业主张和数据边界。

## 7. 评审拓扑

### GATE

- G0 覆盖元闸：哪个创作闭包、信息载体或发布阶段无人检查？
- G1 忠实还原：建议是否能回到重点视频的时间码证据？
- G2 因果边界：是否把人设、粉丝基数、发布时间或点赞关联误写成因果？
- G3 可执行性：方法是否能落成 brief、脚本、镜头或发布动作？
- G4 生产可行：所需素材、人员、工具、时长和剪辑是否真实可做？
- G5 原创迁移：是否只复制博主话术/人设，而没有针对我们重建策略？
- G6 测量闭环：是否定义主指标、守护指标、观察窗口与失败判断？
- G7 安全合规：是否越过版权、平台、健康、商业和隐私边界？

每道闸必须能构造一个会 FAIL 的输入，并用独立证据验收，禁止使用 Skill 自己的输出自证。

### JUDGE

- 内容总编：选题价值与单条承诺。
- 编导：脚本、镜头和认知推进。
- 小红书运营：封面标题、搜索、收藏和评论承接。
- 目标受众：是否愿意看、存、信和行动。
- 剪辑：信息密度、节奏与可删减性。

JUDGE 评价质量，不能覆盖 GATE 的失败。
