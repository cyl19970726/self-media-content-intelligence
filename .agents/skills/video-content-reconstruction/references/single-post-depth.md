# Single-post depth contract

New Builder runs write `depthContractVersion: "single-post-depth@1"`. Existing V1/V2 artifacts without this marker are legacy, not depth-complete. Preserve all existing three-lens fields.

Read frozen `post-source-input.json`. It is an external source channel, never video-internal speech. Register `POST-TITLE` and `POST-COVER` in derivedSources only when actually available, using the frozen input/local cover path. Inspect the independent local cover; never substitute a video frame. Preserve mediaType unknown/image and source availability. No signed URLs or private source text outside the frozen local run.

In visualEditing.openingAnalysis cover exactly [0,min(10,actual media duration)] with ordered contiguous non-overlapping segments. Split on actual shot, text, action or meaning changes; inspect dense frames and refine boundaries with targeted capture when needed. Every segment includes exact/proposed speech, separately observed burned captions, composition, motion, audio role, evidence arrival, viewer question, meaning change, boundary reason, alignmentStatus, evidenceRefs and frameRefs. Use multiple frames for changing states, never one midpoint as proof of an interval. Preserve ASR source text and time conflicts explicitly; do not silently retime it. Unknown speech, captions or audio must be explicit, not inferred. inspectionBasis states sampling resolution and what transitions remain uncertain. Short videos stop at actual duration.

In directingLogic.packagingAnalysis analyze title, independent cover and firstFrame separately: audience, promise, tension, concrete specificity, searchTerms, composition, typeHierarchy and smallSizeReadability. Non-applicable/unreadable fields remain null with a reason in unknowns. Cover readability requires an actual small-size inspection; full-resolution OCR alone is insufficient. Missing sources have state missing, sourceRef null, no evidenceRefs and no conclusions. Available title sourceRef is POST-TITLE, cover is POST-COVER; firstFrame uses a real early frame ID. Retain existing packaging vocabulary, without importing old generated interpretations.

Fulfillment maps title/cover/first_sentence promises to actual bodyEvidenceRefs and states fulfilled/partial/not_shown/unknown. bodyEvidenceRefs contains registered source-evidence IDs (cue, shot, frame, TARGET, OCR or derived source), not knowledge-unit IDs (KU-*), content-block IDs, file paths or JSON pointers. If a knowledge unit supports the promise, cite its specific underlying source evidence here. Author promises are not validated outcomes. Do not explain performance causally from packaging or opening observations. Performance statistics belong to a separate deterministic observational context, never Builder content restoration.

Host supplies `evidence/opening-contact.jpg` and OPEN-* frames at 0.5s resolution. Inspect this whole strip. Do not use ASR cue boundaries as a substitute for observed subtitle/action/meaning boundaries. A spoken clause may contain several caption changes: split them. State boundary uncertainty (typically ±0.5s, refine when consequential). Each segment frameRefs must cover from within 0.55s of its beginning through within 0.55s of its end, with no gap above 1s; include every necessary state. An interval with one midpoint and prose fails. The first 10 seconds report must show the actual caption text sequence, including visible changes before/after ASR timestamps, with original ASR text retained separately.
